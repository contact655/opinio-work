## バグ修正の詳細

### 症状（修正前）

`/profile/edit` の `CareerHistoryEditor.tsx` で、出戻りパターン（A社 → B社 → A社）の経歴を登録すると、A社の全エントリが 1 グループに誤統合される。

例: 003社（現職） → 001社（前職） → 003社（前々職）という経歴が、
003社のグループに「現職の PM ポジション」と「前々職の別ポジション」が同居してしまう。

### 根本原因

`groupStints()` が `Map<string, Stint[]>` で会社名キー集約していたため、連続性を無視してすべての同社エントリを 1 グループに統合してしまっていた。

### 修正内容: groupStints() の差分

**修正前（Map 集約方式）:**
```typescript
function groupStints(stints: Stint[]): StintGroup[] {
  const map = new Map<string, Stint[]>();
  for (const s of stints) {
    const k = groupKey(s);
    if (!map.has(k)) map.set(k, []);
    map.get(k)!.push(s);
  }
  // Map の全エントリから StintGroup を生成 → 出戻りが誤統合される
  for (const [key, positions] of Array.from(map)) { ... }
}
```

**修正後（連続走査方式）:**
```typescript
function groupStints(stints: Stint[]): StintGroup[] {
  if (stints.length === 0) return [];

  const groups: StintGroup[] = [];
  const keyCount = new Map<string, number>();  // key 一意化用カウンタ
  let i = 0;

  while (i < stints.length) {
    const first = stints[i];
    const baseKey = groupKey(first);
    // 連続する同一会社エントリのみ積む（非連続 = 出戻りは別ループで別グループになる）
    const positions: Stint[] = [first];
    let j = i + 1;
    while (j < stints.length && groupKey(stints[j]) === baseKey) {
      positions.push(stints[j]);
      j++;
    }
    // 出戻りで同一 baseKey が2回目以降に現れる場合は "#1" を付与
    const count = keyCount.get(baseKey) ?? 0;
    const uniqueKey = count === 0 ? baseKey : `${baseKey}#${count}`;
    keyCount.set(baseKey, count + 1);

    groups.push({ key: uniqueKey, ... });
    i = j;
  }
  // 現職グループ先頭 → earliestStart DESC
  return groups.sort(...);
}
```

### key 一意化の仕組み

出戻りパターンで同一会社が複数グループになる場合、React `key` と `addingForCompanyKey` の照合に一意性が必要。

| グループ | baseKey | count | uniqueKey |
|---|---|---|---|
| 003（現職・1回目） | `m:uuid-003` | 0 | `m:uuid-003` |
| 001（前職） | `m:uuid-001` | 0 | `m:uuid-001` |
| 003（前々職・2回目） | `m:uuid-003` | 1 | `m:uuid-003#1` |

初回グループは既存の key 形式と後方互換（`#` suffix なし）。

### draftFromGroup のプリフィル追加

「+ このポジションに役割を追加」ボタンを押した際の開始・終了年月を、各グループの実際の期間でプリフィルするよう変更。

```typescript
// 修正前
startedAt: "",
endedAt: "",

// 修正後
startedAt: group.earliestStart,       // そのグループの開始年月をプリフィル
endedAt: group.latestEnd ?? "",        // 現職グループは "" (isCurrent チェックで制御)
```
