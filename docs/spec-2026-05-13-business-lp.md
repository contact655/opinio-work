**作成日**: 2026-05-13
**作成者**: Claude（戦略・設計伴走役）
**位置付け**: Opinio Work の企業流入導線、「採用担当者向け窓口」の整備
**前提**: 2026-05-13 朝のセッションで確定した4つの北極星に準拠

---

## 1. 戦略的意義

### 1.1 現状の課題

`https://opinio.jp/` は求職者・候補者向け LP のみ。企業の採用担当者が流入したときの受け皿がない。
- 「採用サービスを探している企業」が来ても「ここどう使うんだろう」と離脱
- 機会損失が日常的に発生している可能性

### 1.2 解決策

企業向け LP を新規作成し、トップページから明確な動線を設ける。

### 1.3 訴求の優先順位

朝のセッションで Hisato さん判断:

> **「コスト最前面」**: 月額無料・成果報酬モデルの圧倒的優位

理由:
- 業界で唯一に近い「掲載無料」訴求
- 経営者・人事責任者が稟議を通しやすい
- Wantedly Business（月額20万〜）, Green（媒体課金）等への明確な差別化

## 3. ページ構造

### 3.1 セクション1: ヒーロー（最重要、コスト最前面）

**メインコピー**:
```
採用コスト、ゼロから。

月額費用なし、広告費なし、
入社決定時のみ成果報酬。
```

**サブテキスト**:
```
✓ 完全無料で掲載
✓ 営業電話なし  
✓ 入社まで一切請求なし
```

**CTA ボタン**:
```
[ 企業を新規登録（無料） ]
→ /biz/companies/add/new/ に遷移
```

**デザイン要件**:
- 「採用コスト、ゼロから。」は最大級のフォントサイズ
- 求職者向け LP の「先輩に話を聞く。」と同じトーン
- 色味は既存サイトのブランドカラーに準拠

---

### 3.2 セクション2: 料金比較表（コストの圧倒的優位を可視化）

**重要**: 競合の実名は出さない（比較広告規制リスク回避）。「業界平均」「他社例 A」等の匿名表現を使う。

**表構成**:

| サービス | 月額費用 | 成果報酬 | 求人掲載 | 一般的なコスト感 |
|---|---|---|---|---|
| **Opinio Work** | **無料** | **年収30〜35%** | **無料** | **入社決定時のみ** |
| 他社例 A（スカウト型） | 約20万円〜 | なし | 含まれる | 採用ゼロでも月額発生 |
| 他社例 B（媒体型） | 媒体課金 | なし | 別途課金 | 掲載期間中常時発生 |
| 他社例 C（紹介型） | 無料 | 年収30〜35% | 別途課金 | 入社決定時のみ |

**訴求コピー**:
```
他社が「掲載で稼ぐ」のに対し、
Opinio は「採用が成功したときだけ」収益を得ます。

だから、企業も求職者も
質の高いマッチングしか追求できない構造。
```

---

### 3.3 セクション3: 仕組み（3ステップ）

**コピー**:
```
3ステップで採用を開始
```

**ステップ表示**:
```
[ 1 ] 企業を登録（1分）
       無料、メールアドレスだけで開始

[ 2 ] 求人を作成・公開（無料）
       何件でも、何ヶ月でも、無料

[ 3 ] 入社決定時のみ成果報酬
       採用が決まるまで一切請求なし
```

**重要メッセージ**（強調ブロック）:
```
⭐ 応募、スカウト、面談まで全て無料
⭐ お金が発生するのは「入社決定」の一点のみ
```

---

### 3.4 セクション4: 質の訴求（なぜ早期離職ゼロなのか）

**コピー**:
```
人材紹介事業の実績
```

**実績表示**（3カラム）:
```
[ 120社+ ]  [ 200名+ ]  [ ゼロ ]
取引企業    マッチング   早期離職
            実績        （創業以来）
```

**説明文**:
```
なぜ早期離職ゼロを実現できているのか？

Opinio は単なる求人媒体ではありません。
キャリアコンサルタント国家資格と ICF 国際コーチング認定を持つ
代表自身が、一人ひとりの候補者を深く理解した上で
企業に紹介しています。

AI と人間のハイブリッドで、構造的にミスマッチを防ぐ仕組み。
それが「キャリア意思決定インフラ」としての Opinio です。
```

---

### 3.5 セクション5: ターゲット明示（IT/SaaS 特化）

**コピー**:
```
こんな企業に最適です
```

**該当する企業**:
```
✓ IT/SaaS 業界の即戦力人材を採用したい
✓ コストを抑えつつ質の高い採用をしたい
✓ 早期離職を防ぐ採用設計を求めている
✓ 1名でも質の高い人材を採りたい
```

**該当しない企業**（正直に書く、ミスマッチ防止）:
```
（参考）以下のような企業様には不向きです
- 採用ボリュームを最大化したい
- 短期決戦で多数の候補者にスカウトを送りたい
- IT/SaaS 以外の業界での採用が中心
```

### 3.7 セクション7: FAQ

**質問1**:
```
Q. 本当に掲載は無料ですか？
A. はい、月額費用や広告費は一切いただきません。
   求人公開、スカウト、面談まで全て無料でご利用いただけます。
```

**質問2**:
```
Q. 成果報酬の発生条件は？
A. 候補者の入社が確定した時点で、内定後の年収の30〜35%を
   ご請求します。それまでは一切請求が発生しません。
```

**質問3**:
```
Q. 自社で採用したい場合は？
A. 求人公開、スカウト、面談まで全て無料でご利用いただけます。
   人材紹介サービスのご利用は任意です。
   自社の採用力で完結する企業様にも、無料の掲載基盤として
   ご活用いただけます。
```

**質問4**:
```
Q. 営業電話はかかってきますか？
A. ございません。
   ご質問やご相談はサイト内のフォーム、または
   メール（contact@opinio.co.jp）からのみ承ります。
```

**質問5**:
```
Q. どのような業界に対応していますか？
A. 現在は IT/SaaS 業界に特化して運営しています。
   将来的には他業界への展開も予定していますが、
   現時点では IT/SaaS 業界の即戦力人材採用に最適化されています。
```

**質問6**:
```
Q. 登録に審査はありますか？
A. ございません。セルフサーブ型で、登録後すぐに
   求人を公開できます。
   ※ 明らかにスパムや偽情報と判断される場合のみ、
     運営側で削除する場合があります（事後巡回方式）。
```

## 4. 動線の組み込み

### 4.1 トップページ（/）からの導線

求職者向け LP のヘッダーに「採用担当の方はこちら」リンクを追加。

**配置**: ヘッダーナビゲーション右端、ログイン/サインアップボタンの近く
**テキスト**: 「採用担当の方はこちら →」
**遷移先**: 企業向け LP

または、フッターに「For Business」リンクを追加でも可。

### 4.2 既存メニューとの整合

既存の `JobseekerHeader` 内の構造を確認し、最も自然な位置に配置すること。
- 求職者の体験を損なわないこと
- 「企業向けでは？」とは決して感じさせない、控えめな位置に

## 7. デザインガイドライン

### 7.1 トーン

- 求職者向け LP「先輩に話を聞く。」のトーンと統一
- 落ち着いた配色、信頼感のあるデザイン
- 派手な装飾は避ける（プレミアム感を出す）

### 7.2 強調すべき要素

- 「無料」のキーワードは赤や緑などで強調しない（白黒の太字でOK）
- 数字（120社、200名、ゼロ）は視認性重視
- CTA ボタンのみブランドカラー（既存サイトと統一）

### 7.3 モバイル対応

- レスポンシブ必須
- スマホでも比較表が読める設計（カラムスクロール or 縦並びに切替）
