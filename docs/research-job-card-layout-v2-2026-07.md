# 求人リストカード レイアウト再設計案（2026-07-09）

## 1. 現状の構造と空白の原因

### 現在のDOM構造（横に並ぶ3ブロック）

```
┌─────────────────────────────────────────────────────────┐
│ [ロゴ36px]  [中央 flex:1 ←左端固定]        [右108px]    │
│              タイトル（nowrap, 1行）         年収（右寄せ）│
│              会社名・フェーズ・場所・勤務形態  ────────   │
│              先輩strip（inline-flex, 左から） ♡  詳細→  │
│              [dept] [面談受付中]                         │
└─────────────────────────────────────────────────────────┘
```

### 空白が生まれる構造的原因

1. **中央ゾーンの要素がすべて左揃え**  
   `flexDirection: column` + `gap: 2` で縦積み。幅 `flex:1` をもらっているが、  
   各要素のコンテンツ幅（タイトル〜100〜200px、バッジ行〜80px）が短く、  
   右側 200〜300px が自然に空く。

2. **右ゾーンが `width: 108px; flexShrink: 0; borderLeft`**  
   画面端に張り付いた固定幅の「島」になっている。  
   中央との境界が明確な縦線で分断されており、空白感が強調される。

3. **1280px以上のデスクトップでは中央ゾーンが 800〜900px に達する**  
   サイドバー(220px) + ギャップ後のカード幅が広く、  
   中央のコンテンツ（最長でも300px程度）が左の1/3に固まる。

### 現在の要素レイアウト（デスクトップ 1280px 想定）

```
|←ロゴ46px→|←───────── 中央 〜880px ─────────────────────→|←108px→|
  [36px]    タイトル（200pxくらいで切れる）                  年収13px
            会社名・場所・勤務形態（150px程度で終わる）       ────
            先輩strip（自然幅200px程度）                       ♡詳細
            [dept] [面談受付中]（100px程度で終わる）
            ← 左端から600pxが空洞 →
```

## 2. レイアウト改善案

---

### 案A：タイトル行に年収を統合（2行構造）

**概念図:**

```
[ロゴ]  タイトル（flex:1, 1行）               400〜600万円
        会社名・場所・勤務形態 · [dept] [面談]    ────────
        先輩strip（あれば）                    ♡  詳細→
```

**変更の要点:**

- 右ゾーンを廃止（または幅を縮小）
- タイトルと年収を同じ行に配置  
  → `display: flex; justifyContent: space-between` でタイトル行右端に年収
- 「会社名・場所」行の右端に `[dept] [面談受付中]` バッジを移動  
  → `gap` + `marginLeft: auto` で右寄せ

```
[ロゴ]  [タイトル ─────────────── flex:1 ──] [年収 / 応相談]
        [会社·場所·勤務形態]  [dept][面談]←marginLeft:auto
        [先輩strip]                          [♡] [詳細→]
```

**空白の埋まり方:**  
タイトル行が横幅全体を使い、縦線の「壁」がなくなる。  
バッジが右側に流れて中央〜右の空間を活用。

**メリット:**
- 年収がタイトルと同じ行なので「案件」として一目で完結する
- 縦線の分断がなくなり、カード全体に統一感
- タイトルの行が長く見えて情報量の印象が上がる

**デメリット:**
- 年収の「縦揃え」がなくなる（異なるカード間での年収比較がしづらい）
- タイトルが長い場合に年収が押し出される可能性（minWidth を要設定）

**実装難易度:** ★★（中央ゾーンの flexDirection を変えるだけで大半は対応可）

---

### 案B：タグ行に年収を同居させる（現構造を最小変更で修正）

**概念図:**

```
[ロゴ]  タイトル（flex:1）        [年収 右寄せ, marginLeft:auto]
        会社名・場所・勤務形態
        [dept] [面談受付中] ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ [♡ 詳細→]
        先輩strip
```

**変更の要点:**

- 右ゾーン（width:108px 固定）を廃止し、代わりに中央ゾーンの中で年収を `marginLeft: auto` で右寄せ
- タイトル行を `display: flex` にして年収を右端に置く
- バッジ（♡・詳細）をバッジ行の右端に `marginLeft: auto` で移動
- borderLeft の縦線を削除

```
[ロゴ]  [タイトル（flex:1）]                    [400〜600万円]
        [会社·場所·勤務形態]
        [dept][面談] ─────────────── [♡ 気になる] [詳細 →]
        [先輩strip]
```

**空白の埋まり方:**  
タイトルと年収が両端に張り、バッジ・CTAも右端を埋める。  
中央に縦線がなく、左→右の流れがスムーズ。

**メリット:**
- 現状の縦積み（3〜4行）構造を維持しやすい
- ♡と詳細CTAが自然にカード右下に来てUI慣習に合う
- 右ゾーンの「固定島」がなくなり、コード量も減る

**デメリット:**
- 年収のフォントサイズ・位置が案Aより目立ちにくい（タイトルと同行のため小さくせざるを得ない or バランス調整が必要）

**実装難易度:** ★（右ゾーン削除 + marginLeft:auto の付け替えがメイン）

---

### 案C：LinkedIn型・3列グリッド

**概念図（LinkedIn Jobsカードに近い）:**

```
[ロゴ]  タイトル（flex:1）
        [会社名]  [場所・リモート]  [年収]    ←同じ行に3情報
        [dept] [面談] [先輩strip]            ←バッジ行が横に広がる
        ─────────────────────────  [♡ 気になる]
```

**変更の要点:**

- 中央ゾーンを2行に絞る
  - 1行目: タイトル（全幅）
  - 2行目: `display:flex; justifyContent:space-between` で 会社名 / 場所 / 年収 を3列横並び
  - 3行目: バッジ + ♡ボタン（同行右端）
- 先輩stripはバッジ行に統合するか省略

```
[ロゴ36]  タイトル
          [Salesforce Japan] · [東京] · [リモート]   [400〜600万円]
          [セールス][面談受付中] [先輩2名 →]         [♡]
```

**空白の埋まり方:**  
2行目で会社名・場所・年収が横幅全体に分散。  
3行目でバッジが左から伸び、♡ボタンが右端を押さえる。

**メリット:**
- もっとも「横幅を使いきれている」見た目になる
- 年収が2行目右端に来るので各カード間で縦揃え維持
- LinkedIn等のグローバルUIパターンに近く、違和感が少ない

**デメリット:**
- 2行目が詰まって見える可能性（会社名・場所・年収が1行に並ぶ）
- 先輩stripをどこに置くかが課題（独立行だと現状と変わらず高さが増す）
- 実装変更量が最も多い

**実装難易度:** ★★★（構造を大きく変える。バッジ行・先輩stripの再配置が必要）

## 4. ★おすすめ案とその理由

**→ 案B（中央ゾーン内で右寄せ、右ゾーン廃止）を推奨**

理由:

1. **現状のコードへの変更が最小**  
   右ゾーン（約40行）を削除し、タイトル `span` を `flex; justifyContent:space-between` に変えるだけ。  
   バッジ行右端に ♡・詳細を移動するのも `marginLeft: auto` 1行の変更。

2. **年収の縦揃えが維持される**  
   各カードの年収が「タイトルの右端」に揃うため、スキャン時に比較しやすい。

3. **縦線の「壁」がなくなり、空白感が解消される**  
   現状は `borderLeft: 1px solid var(--line-soft)` + 固定幅108pxの島が分断感を生み出している。  
   廃止するだけで見た目が大幅に改善。

4. **先輩stripの問題は別途解決できる**  
   先輩stripは既存のまま（独立行）で、横幅問題の解消後に別途バッジ行への統合を検討。

変更対象: `JobsClient.tsx` の `JobListCard` のみ
