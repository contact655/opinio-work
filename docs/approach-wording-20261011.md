# 声かけの言葉の見直し（企業側の表示だけ）— 2026-10-11

柴さんの指示。企業の担当者が「声かけ」「承認待ち」の意味を画面だけで理解できなかったため、
LinkedIn Recruiter の InMail 画面を参考に言葉と画面を見直した。

**変えたのは企業側の表示だけ。** DB の値（`accepted_at` など）・API・状態のキー（`pending` / `accepted` / `expired`）は変えていない。
**求職者側の言葉（「話してみる」「今回は見送る」、設定画面の「承認待ちの声かけ」）は変えていない。**

## 足したもの

- **ヘルプ** `/biz/help/approaches`（見出しの横「声かけとは？」から）。仕組み・送れる数・企業に表示されること・書き方のコツ・提案との違い。
- **仕組みの3ステップ**（`components/approaches/ApproachGuide.tsx`）。0件のときは大きく、1件以上送ったあとは1行にして「仕組みを見る」で開く。
- **数字のカードの「?」**。押すと1文の説明がカードの中に開く（ボタンなのでキーボードでも開ける。Esc で閉じる）。
- **0件のときの案内**。「いま声をかけられる候補者：N人」は候補者検索の「声かけを受け取る方のみ」と同じ判定（`loadCompanyCandidates` → `can_send_company_approach_many`）。取れなかったら数字を出さない。
- **候補者検索の `?approach=1`**。「声かけを受け取る方のみ」をオンにして開く。

## 残しているもの（企業側でも直していない「承認」）

声かけ以外の意味なので変えていない: 運営による企業の審査（ホームの「承認後、候補者検索・求人公開を…」）、
企業への参加依頼（`/biz/companies/add`）、チームの招待（`/biz/members` の「承認待ち」）。
