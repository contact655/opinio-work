## 2. 検索 UI の設計詳細

### フローティングバッジの選定（候補 A/B/C から選択）

**選定: 候補 C 変形**「田中さん（元Sansan）/ この方をご紹介できます」

**選定理由:**
- 求職者 LP の「佐藤さん（元HubSpot）似た経歴の私に、話しませんか？」と
  同じ「人間名 + 出身企業 + 一言メッセージ」の3要素構成
- 「対話的・人間的なニュアンス」を最も強く保持
- メンターが「企業に向けて候補者を紹介する」文脈に自然にはまる
- 候補 A（推薦コメント付き）は文字が長すぎてバッジに収まりにくい
- 候補 B（現状の応募前メンター面談制度）は絵文字のみで人間感がない

**実装詳細:**
- アバター: 円形 32×32px, グリーングラデーション `linear-gradient(135deg, #059669, #047857)`, 「田」イニシャル
- 吹き出しスタイル: borderRadius 14, shadow + ring
- 位置: `bottom: -16, right: -8`（求職者 LP と同じ）

### 検索ボックス

| 項目 | 内容 |
|------|------|
| ラベル | 「経験で絞り込む」（UPPERCASE, ink-mute） |
| プレースホルダー | 「エンタープライズセールス経験者」 |
| アイコン | 虫眼鏡 SVG（royal color, 13px）|
| ボーダー | `1.5px solid var(--royal)`（求職者 LP と同じフォーカス状態） |

### 候補者カードリスト（3件）

求職者 LP の求人カードと同一スタイル（`background: var(--line-soft)`）に変換:

| 列 | 求職者 LP（求人） | 企業 LP（候補者） |
|----|-----------------|-----------------|
| アイコン | 会社ロゴ文字（32px square, rounded） | 候補者イニシャル（32px square, rounded） |
| 小テキスト（上） | 会社名（ink-mute, 11px） | 出身企業（ink-mute, 11px） |
| 大テキスト（中） | 職種名（bold, 13px） | 氏名 + 役職（bold, 13px） |
| タグ（下） | ライフスタイルタグ | スキルタグ |
| 右端 | 年収レンジ（ink-soft） | ★ 面談済バッジ（success-soft/green） |

### フッター
- Chat bubble SVG + 「すべての候補者に『Opinio編集部の推薦コメント』付き」
- 求職者 LP の「すべての求人に『Opinio編集部の見解』付き」と対称

## 3. 左側コピーの変更

### 変更箇所

| 要素 | Before | After |
|------|--------|-------|
| メインコピー（H1） | 「採用コスト、<br />ゼロから。」 | **変更なし**（維持） |
| サブテキスト | 「月額費用なし、広告費なし、<br />入社決定時のみ成果報酬。」 | 「IT/SaaS業界の即戦力に、<br />経験で絞り込んで、出会う。」 |
| チェックリスト | 維持 | **変更なし** |

### 変更理由

旧サブテキスト「月額費用なし、広告費なし…」は料金訴求だが、
Point1（InfraBlock 01/FREE）で既に丁寧に訴求しており重複していた。
新サブテキスト「経験で絞り込んで、出会う。」は：
- 右側の検索ボックスラベル「経験で絞り込む」と**直接呼応**
- 検索 UI モックアップが「どう使うか」を左コピーが説明する構造になる
- 「採用コスト、ゼロから。」（コスト訴求） + 「経験で絞り込んで、出会う。」（体験訴求）
  の2軸でヒーローが完結する
