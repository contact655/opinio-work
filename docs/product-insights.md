## 2026-05-05 #001: 社員プロフィールページの情報密度が低い

### 背景

Step 0 完走直後、ユーザーとして opinio.jp の企業ページから
社員プロフィールページに遷移した際、情報量の薄さに気づいた。

### 観察された事実

URL: `opinio.jp/u/b46ced49-7a6f-4c69-aeb3-daf435c7f0e3`(現役社員_041)

表示されている情報:
- 名前: 現役社員_041
- 「自己紹介は未設定です」
- キャリア: 2020.09 〜 現在 / バックエンドエンジニア / テスト株式会社_021
- 「Opinio のプロフィールページ・登録して情報収集を始める」誘導

それ以外の情報は **一切ない**。

### なぜこれが重要か

opinio.work の 7 つの設計哲学:
- 「**対話の産業を作る**」
- 「**編集部介在型の対話**」
- 「**情報の非対称性をなくす**」

これに対して、社員プロフィールが「名前 + 職種 + 会社名」だけでは、
**対話のきっかけになる情報が決定的に不足**している。

求職者の心理:
- 「この人がどんな考えを持っているか知りたい」
- 「自分と価値観が合いそうか知りたい」
- 「面談する前に人柄を知りたい」

これに応える情報がない。
**Wantedly や LinkedIn 以下の情報量** で、opinio.work の独自性が
プロフィール段階で消えている。

事業上のリスク:
- Phase η で 30 社投入しても、社員側が何を書けばいいかわからない
- 求職者側が「話を聞く」ボタンを押す動機が生まれない
- 競合(Wantedly, Green)との差別化が成立しない

### 解決の方向性(仮説)

#### 情報レイヤーの整理

| レイヤー | 内容 | 現状 |
|---|---|---|
| 1. 経歴 | 現職・過去の職歴 | △(現職のみ) |
| 2. 人物理解 | 入社理由・仕事内容・価値観・将来展望 | × |
| 3. 対話のきっかけ | どんな人と話したいか・業界観・趣味 | × |
| 4. 編集部視点 | 第三者視点の紹介文・対話を読む観点 | × |

#### 短期対応案

- ow_jobseeker_experiences の表示活用(既にデータ構造はあるはず)
- 「自己紹介は未設定です」の入力促進 UI
- 入社理由・現在の仕事内容の新規フィールド検討

#### 中期対応案

- 編集部紹介文(opinio.work の独自性、編集チームが書く)
- 質問テンプレート(「この人に聞きたいこと」を可視化)
- 個人記事 / ミニコラム(編集部インタビュー or 社員寄稿)

#### 長期対応案

- 対話履歴のサマリー(過去の casual meeting でよく聞かれた質問)
- マッチング示唆(「あなたとこの人は〜が共通」)

### 関連する Phase / Step

- Phase ν 完走後、Phase η(30 社投入)前に **必ず議論すべき**
- 議論内容によっては Phase ν-X として独立した整備 Phase が必要かも

### ステータス

OPEN — 2026-05-05 時点で記録のみ。議論は Phase ν 完走後。
