# 提案を「求職者が先に答える」形に変えた件 ── 弁護士確認用（2026-10-11）

⚠️ **規約・プライバシーポリシーは書き換えていない**（`content/legal/` は触っていない）。
この文書は「何が・いつ・誰に届くか」と、書き直しが要りそうな箇所の一覧だけ。文案は確認のあとで作る。

---

## 1. 新しい流れ

| 段 | 何が起きるか | 企業に届くもの |
|---|---|---|
| ① OPINIO が提案を作る | 経歴・求人・部門などの根拠が2つ以上そろった「求職者 × 企業 × 求人」の組。**求職者にだけ届く**（マイページの「提案」とベル） | **何も届かない**（名前・提案したこと・件数の内訳とも） |
| ② 求職者が「話を聞いてみたい」を押す（任意で200字までのひとこと） | 企業の設定で分かれる（③） | **公開プロフィール**（氏名・顔写真・見出し・職歴など。`/u/[id]` と同じもの）、**ひとこと**、**根拠** |
| ②' 求職者が「今回は見送る」を押す（理由は任意） | 終了 | **何も届かない**（見送ったことも理由も） |
| ②'' 30日間答えない | 終了 | **何も届かない** |
| ③A 企業の設定「すぐにメッセージを始める」（既定） | その場で会話が作られる。会話の先頭に案内の行「◯◯さんが提案を見て、話を聞いてみたいと答えました。」、続けて求職者のひとこと | メール「◯◯さんが提案を見て『話を聞いてみたい』と答えました」（ひとことの中身はメールに入れない） |
| ③B 企業の設定「確認してから会うかを決める」 | 企業が14日以内に「会う」か「今回は見送る」を選ぶ。会うなら③Aと同じ会話ができる | ②と同じものが企業の画面に出る。メールも同じ |
| ③B' 企業が見送る・14日答えない | 終了 | 求職者には「この提案は終了しました」とだけ出る（企業が見送ったことは伝えない） |

**応募にはならない**（画面にも書いてある）。提案から始まった会話は、企業が送るメッセージの枠（月10通・返事待ち10件）を使わない。

### 企業に出す数字（人数だけ）

`/biz/proposals` の「今月の提案」と `/biz/analytics` の「提案」タブ:
**ご紹介した方 ／ 話を聞いてみたいと答えた方 ／ 面談につながった方** の人数。
- 名前・内訳は出さない
- **1日1回の集計**（日本時間の今日の0時より前のものだけ数える。「毎朝更新」と表示）。
  すぐ数字が動くと「いま誰かに紹介された」ことが分かってしまうため

### 誰に作るか（変えていない）

- 求職者が「転職について」で企業からの連絡を受け取る側を選んでいる人だけ（スカウトと同じ判定）
- 在籍中・過去の勤務先、手動でブロックした企業には作らない（`can_send_scout()` と同じ判定）
- ★**求人つきでしか作らない**（2026-10-11 から。`job_id` を必須にする）

## 2. 以前（2026-10-09 〜 10-11）との違い

| | 以前 | 今回 |
|---|---|---|
| 企業に見えるタイミング | **提案の時点から**、企業に候補者の氏名と根拠が見えていた（双方が「会いたい」と答えて会話が開く） | **求職者が「話を聞いてみたい」と答えるまで、企業には何も見えない** |
| 求職者が見送ったとき | 企業には「この提案は終了しました」と出ていた（提案があったことは企業に分かる） | 企業には**何も出ない** |

→ **企業に渡る範囲は狭まる方向の変更**。ただし「求職者が押した瞬間に、その企業へプロフィールとひとことを渡す」という**提供の場面が新しく生まれる**。

## 4. 確認したいこと

1. §5-1 の限定列挙に「提案への回答」を足す必要があるか（それとも求職者の行為として§5-1の外で読めるか）
2. 「話を聞いてみたい」を押す直前の画面の説明（下）で、提供の同意として足りるか
   > 押すと、◯◯にあなたのプロフィールとひとことが届き、メッセージでやり取りできるようになります。応募にはなりません。見送っても会社には伝わりません。
   > （企業の設定が「確認してから」のときは）押すと、◯◯にあなたのプロフィールとひとことが届きます。◯◯が「会う」と答えると、メッセージでやり取りできるようになります。
3. 企業に出す「ご紹介した方」の人数（1日1回・名前なし）が、求職者の情報の提供にあたらないと言えるか
4. 職業安定法上、提案（OPINIO が求人つきで企業をご紹介する）が募集情報等提供の範囲に収まるか
   （掲載規約 第2条3項の位置づけとの整合）
