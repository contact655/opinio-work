# 規約改定案：企業に表示される項目（氏名・年齢）を実態に合わせる（2026-10-12 作成）

> **この文書は案です。** 本番の規約ページ（`content/legal/*.md`）は変えていません。
> 改定日・告知・弁護士の確認は柴さんの判断です。

## なぜ改定が要るか

| | いまの規約 | 実態（2026-10-12） |
|---|---|---|
| 氏名 | プライバシーポリシー 5-1 で「**除く**」 | 企業の候補者一覧・右欄に**出ている**（以前から） |
| 生年月日 | 同じく「**除く**」 | 生年月日そのものは出していない。**年齢として出す実装を作った**（本番では無効。`CANDIDATE_AGE_DISPLAY_ENABLED`） |
| 求職者向け利用規約 | 企業にどの項目が見えるかを**書いていない** | `/mypage/settings` の「企業からの見え方」には書いてある |

⚠️ 氏名の食い違いは**年齢と関係なく、いま既に起きている**。年齢を出すかどうかに関わらず直す必要がある。

⚠️ 年齢の表示・絞り込みは、**この改定が効力を持ち、弁護士の確認が済むまで本番では無効**のまま（CLAUDE.md「年齢」の節）。

## 1. プライバシーポリシー 5条1項（提供の条件）

### 現行（`content/legal/privacy-policy.md`／最終改訂日 2026年8月1日）

```
| 提供する場合 | 提供される情報 |
|---|---|
| **求職者がスカウトの受け取りを「受け取る」に設定した場合** | プロフィール情報（氏名、生年月日、連絡先を除く）が、利用企業の管理画面上で閲覧可能になります |
| **求職者が求人に応募した場合** | 応募先の利用企業に対し、プロフィール情報および連絡先が提供されます |
| **求職者がスカウトに返信した場合** | 当該利用企業に対し、連絡先が提供されます |
```

### 改定案

```diff
 | 提供する場合 | 提供される情報 |
 |---|---|
-| **求職者がスカウトの受け取りを「受け取る」に設定した場合** | プロフィール情報（氏名、生年月日、連絡先を除く）が、利用企業の管理画面上で閲覧可能になります |
+| **求職者が「転職について」で利用企業からの連絡を受け取る意思を示した場合** | プロフィール情報（**氏名を含み、連絡先を除く**）が、利用企業の管理画面（候補者の一覧および詳細）で閲覧可能になります。**生年月日は、生年月日そのものではなく、生年月日から算出した年齢として表示されます。** 表示される項目は、別表のとおりです |
 | **求職者が求人に応募した場合** | 応募先の利用企業に対し、プロフィール情報および連絡先が提供されます |
-| **求職者がスカウトに返信した場合** | 当該利用企業に対し、連絡先が提供されます |
+| **求職者が利用企業からのメッセージに返信した場合** | 当該利用企業に対し、連絡先が提供されます |
```

#### 追加する別表（5-1 の下）

```
#### 別表：利用企業の管理画面に表示される項目

| 画面 | 表示される項目 |
|---|---|
| 候補者の一覧 | 氏名、年齢（生年月日を登録している場合）、社会人年数、現在の職種と勤務先、お住まいの地域、転職への意向、職種と経験年数（一覧では2つまで）。見出しと希望勤務地は一覧に表示されないが、管理画面に渡るデータに含まれる |
| 候補者の詳細 | 上記に加え、**本サービスを最近利用した時期（「3日以内」「1週間以内」「1か月以内」「それ以前」の4段階。正確な日時は表示しません）**、転職への意向とその更新日、職歴、学歴、スキル、自己紹介、語学、資格、実績・受賞、メディア掲載、外部リンク、OPINIO での投稿 |
| 絞り込みに使われる項目（画面には表示されないものを含む） | 希望年収、雇用形態、希望の働き方、転職への意向とその更新時期、年齢、**最近利用した時期** |

※ 生年月日、メールアドレス、電話番号は表示されません。
※ 利用企業は、候補者を社内で「気になる」に保存できます（利用企業の担当者の間で共有され、求職者には通知されません）。
※ 公開範囲を「非公開」にした場合、または「転職について」で「今は考えていない」を選んだ場合は、候補者の一覧に表示されません。
```

⚠️ 「絞り込みに使われる項目」の**年齢**は、絞り込みを本番で有効にする場合だけ書く。無効のまま改定するなら外す。
⚠️ **最近利用した時期**（2026-10-12 追記）も同じ。`CANDIDATE_ACTIVITY_ENABLED` を本番で有効にする場合だけ書く。
⚠️ 2026-10-12 追記: 一覧の項目をカードの整理（「転職検討中」の表示をやめ、転職への意向を全員に表示）に合わせて直した。「気になる」（★）の保存を追記した（企業側の社内の操作で、求職者の情報が新たに渡るものではないが、記録として残るため）。
⚠️ 「スカウト」の語は 2026-10-08 にスカウトを廃止したので、この改定で「利用企業からの連絡（メッセージ）」に揃える。
   **5-3〜5-5（スカウトの受け取り設定・自動ブロック・手動ブロック）も同じ語の整理が要る**（この案の範囲外）。

### 2-1（取得する情報）は変えない

`氏名、生年月日、性別、メールアドレス、電話番号、居住地域` を取得することは既に書いてある。変えるのは「何を企業に見せるか」だけ。

## 2. 求職者向け利用規約（`content/legal/terms-of-service-jobseeker.md`）

### 現行 第7条（プロフィールの公開範囲）

```
1. ユーザーは、本サービス上にプロフィールを登録することができます。
2. ユーザーは、プロフィールの公開範囲を、次の3つから選択することができます。（表）
3. 登録時の初期設定は「ログインユーザーのみ」です。…
4. ユーザーは、いつでも公開範囲を変更することができます。
5. 公開範囲の設定にかかわらず、第8条に定める在籍企業からのスカウトは、自動的にブロックされます。
```

### 改定案（第7条に第6項を足す）

```diff
 5. 公開範囲の設定にかかわらず、第8条に定める在籍企業からのスカウトは、自動的にブロックされます。
+6. ユーザーが「転職について」で利用企業からの連絡を受け取る意思を示した場合、利用企業の候補者の一覧および詳細に、
+   ユーザーのプロフィールが表示されます。表示される項目は、プライバシーポリシー第5条第1項の別表のとおりです。
+   **年齢は、ユーザーが登録した生年月日から算出して表示し、生年月日そのものは表示しません。**
+   氏名は表示され、メールアドレスおよび電話番号は表示されません。
+   また、ユーザーが本サービスを最近利用した時期（「3日以内」「1週間以内」「1か月以内」「それ以前」の区分）が表示されます。
+   正確な利用日時は表示しません。
```

⚠️ 第5項の「スカウト」も同じ語の整理が要る（範囲外）。

## 3. 改定の告知方法（案）

| # | 方法 | 中身 | 実装の手がかり |
|---|---|---|---|
| ① | **サイト上の告知** | 規約ページの冒頭に「規約改定のお知らせ」（改定日・効力発生日・変更点の要約）。効力発生日の **30日前**から掲示 | 求職者向け規約には既に「規約改定のお知らせ」の枠と、条文の上の「⚠️ 本条第◯項は◯月◯日に変更されます」の書き方がある（2026-09-27 の改定と同じ形） |
| ② | **登録メールアドレスへの通知** | 実ユーザー（`is_test` / `is_system` を除く）全員に1通。件名「利用規約・プライバシーポリシー改定のお知らせ」、本文に変更点と効力発生日、規約ページへのリンク | `lib/notify/email.ts`（dev では送らない）。**宛先の数え方は「本番で検証用アカウントを作らない」の節の SQL で `is_test` を除く**。2026-10-12 時点の実ユーザー 41人 |
| ③ | **次回ログイン時の表示** | ログイン後の最初の画面（`/mypage`）の上部に「利用規約・プライバシーポリシーを改定しました（◯月◯日から）」と「内容を見る」。閉じたら二度と出さない | 閉じた記録は本人ごとに要る（`ow_terms_agreements` に「確認した」を記録する形が既存の仕組みに近い）。**同意を必須にするかは弁護士の確認後に決める** |

⚠️ 年齢・氏名の表示は、本人にとって**新しく見えるようになる情報**を含む。告知は①だけで済ませず、②③を併せるのが安全。
⚠️ 効力発生日より前に年齢の表示を本番で有効にしないこと（`CANDIDATE_AGE_DISPLAY_ENABLED` を入れるのは効力発生日以降）。

## 4. 確認してほしいこと（弁護士）

1. 企業の候補者一覧に**年齢を表示**することと、労働施策総合推進法9条（募集・採用時の年齢制限の原則禁止）・職業安定法5条の4（的確表示）との関係
2. 企業が**年齢で絞り込み・並び替え**できること（`CANDIDATE_AGE_FILTER_ENABLED`）が、事業主の禁止行為を手助けすると評価されないか
3. 氏名・年齢の表示を、規約改定（告知のみ）で足りるか、**本人の個別の同意**が要るか
4. 最近の利用時期（4段階）を企業に表示すること、その記録（最後に利用した日時）を取ることの扱い
