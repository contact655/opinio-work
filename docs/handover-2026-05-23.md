## 残タスク（優先順）

### 🔴 最優先: groupStints() 連続走査書き直し

`/profile/edit` の `CareerHistoryEditor.tsx` 内 `groupStints()` 関数に出戻りパターンのバグあり。

**症状:** 同社への出戻り経歴（003 → 001 → 003）が、003 の全ジョブを 1 グループに統合してしまう（PMM 在籍期間中も 003 グループに含まれる）。

**根本原因:** `groupStints()` が Map ベースで全同社エントリを集約するため、連続性を無視して統合する。

**修正方針:** MergedTimeline の `groupSameCompanyEntries()` と同様に、**連続走査（consecutive scan）**に変更する。

**影響範囲:** `/profile/edit` のみ（`/mypage`・`/u/[id]` の MergedTimeline は正常動作確認済み）。

**参考:** `docs/bug_investigation_revisit_pattern.md`

## 戦略的な大決定（本日確認・確定）

### 北極星: キャリア意思決定インフラ

Opinio Work が目指すポジション。「求人ポータル」でも「マッチングサービス」でもなく、「キャリアを考え続ける人のためのインフラ」。

### 確定した哲学

| 原則 | 内容 |
|---|---|
| **数字を出さない** | マッチ度・星評価・実績数を一切表示しない。`success_count` / `total_sessions` も UI 削除。企業カードの「現役N名/OBOQ M名」は意思決定シグナルとして許容（人数ではなく実態の可視化）|
| **運営仲介** | メンターへの直接予約（calendly_url）を廃止し、編集部が介在する `ow_consultation_requests` フローに統一 |
| **悩みベース主軸** | `/mentors` の主軸は職種・業種フィルタではなく悩みカテゴリカルーセル。ユーザーは「誰に相談するか」ではなく「何を相談するか」から入る |
| **0名表示しない** | メンターが 0名の場合はカルーセルもグリッドも非表示。揃うまで待つ |

### メンタープロフィール = ユーザープロフィール + メンター属性

`ow_users` をベースとし、メンター固有情報は `ow_mentors` に分離するという構造が確定。

```
ow_users（全ユーザー共通）
  ├ is_mentor / is_active_mentor / mentor_themes（権限・属性フラグ）
  └ ow_experiences（経歴 — /u/[id] と /mentors/[id] で共用）

ow_mentors（メンター固有の表示情報）
  ├ bio / catchphrase / question_tags / concerns
  ├ current_company / current_role（表示用テキスト）
  └ user_id → ow_users.id（NOT NULL、1:1 リンク）
```

これにより `/mentors/[id]` の経歴タイムラインは `ow_experiences` から直接取得でき、`/u/[id]` と同一コンポーネント（MergedTimeline）を再利用できる。
