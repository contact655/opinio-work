# 積み残し: 企業ページ（/biz/company）の作り直しのあとで（2026-10-12 記録）

2026-10-12 に企業ページの編集画面を1ページにし、反映を「公開する」1つにまとめた（柴さんの指示）。
そのとき見つけたが、**今回は直していない**もの。

## 1. 求人ページで、会社説明が書式なしで出る

| | 企業ページ（/companies/[id]） | 求人ページ（/jobs/[id]） |
|---|---|---|
| 会社説明（`ow_companies.description`） | **Markdown として描画**（`components/common/Markdown`） | **改行で段落に分けるだけ**（`components/jobs/JobDetailView.tsx` の「企業について」） |

- 企業説明の入力欄（`MarkdownEditor`）には「見出し・太字・箇条書き・リンク」のボタンがあり、記号（`##` `**` `- ` `[ ](https://)`）が入る。
- 企業ページでは書式として出るが、**求人ページでは記号がそのまま文字として出る。**
- 直すなら `JobDetailView.tsx` の `company.about` を `<Markdown>` で描画する（企業ページと同じ部品）。
  ⚠️ 入力欄と描画は**セットで**扱うこと（CLAUDE.md「markdown は描画側を対応させて解決した」）。片方だけだと記号が出る。
- 実データへの影響（2026-10-12 時点）: 企業説明は改行区切りの段落がほとんどで、記号を使っている企業はまだ少ない。
  入力欄のボタンが動くようになったので（それまでは押しても何も起きていなかった）、これから増える。

## 2. 掲載前でページが見える企業は、自分で変更を公開できない

`is_published = true` かつ `listing_status = 'draft'`（企業一覧に未掲載だがページは見える）の企業は、
「変更を公開する」を押せない（「掲載を依頼する」だけ）。変更は運営が掲載にする操作の中で反映される（柴さんの指示どおり）。
経歴のリンクから見られるページの内容が、掲載まで古いままになる。必要なら運営画面で個別に反映する手段を作る。
