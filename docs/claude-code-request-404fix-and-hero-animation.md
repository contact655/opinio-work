## タスク1: /about・/industries の 404修正

### 現状
- `/about` と `/industries` が404を返している

### やること
1. 両ルートが存在するか確認
2. 存在しない場合は、フッターやヘッダーなど他の場所からリンクされているか `grep -r "/about\|/industries" src/` で確認
3. リンクされている場合は、以下のどちらかで対応:
   - **対応A**: シンプルなプレースホルダーページを作成（「準備中」表記）
   - **対応B**: リンク自体を削除（コンテンツが当面ない場合）
4. どちらの対応を取るか、事前調査レポートで判断材料を提示してから判断（迷う場合はAで進める）

## タスク2: トップページのヒーロー職種ローテーションアニメ

### 仕様
- **対象**: トップページ（/）のヒーローセクションのみ
- **スタイル**: フェードイン/アウトで職種テキストが切り替わる
- **切り替え間隔**: 2.5〜3秒（自然に読める速度）
- **トランジション**: opacity 400ms程度のease-in-out

### 実装方針
- 既存のヒーローコピー構造を尊重し、職種部分だけを動的にする
- 例: `次のキャリアを、[ エンタープライズセールス ] で。` のようにコピー中の特定箇所だけが切り替わる
- 現状のヒーローコピーに合わせて、最も自然な箇所を選んで実装

### 職種候補（8個、IT/SaaS中堅以上ターゲット）
1. エンタープライズセールス
2. カスタマーサクセス
3. プロダクトマーケティング
4. インサイドセールス
5. プロダクトマネージャー
6. フィールドセールス
7. ビジネス開発
8. マーケティング

### 実装上の注意
- `'use client'` でクライアントコンポーネント化が必要
- `useEffect` + `setInterval` で定期切り替え
- アクセシビリティ: `prefers-reduced-motion` を尊重し、reduce設定のユーザーには切り替えを無効化（最初の職種を固定表示）
- レイアウトシフトを起こさないように、最長の職種名に合わせた `min-width` を設定
