# 求人カード再設計 調査レポート

作成日: 2026-07-09

---

## 1. 現状の実装把握

### カードの種類

`/jobs` は **2種類のカード** を持つ。

| コンポーネント | 用途 | 行数 |
|---|---|---|
| `JobCard` (L131-559) | グリッド表示（デスクトップ・タブレット）| 縦型カード |
| `JobListCard` (L901-1203) | リスト表示（デフォルト・全幅）| 横型カード |

現在のデフォルト表示は **JobListCard** のリスト表示。グリッド（JobCard）はビュー切り替えボタンで選択可能だが、モバイルでは非表示（`@media (max-width: 767px) { .jobs-grid-desktop { display: none; } }`）。

---

### JobCard（グリッド用・縦型）の構造

```
┌─────────────────────┐  height: ~280〜320px
│  グラデーションヘッダー │  height: 60px
│  [NEW] [HOT]        │
│  [ロゴ44px 下にはみ出]│
├─────────────────────┤
│  padding: 28px top  │  ← ロゴはみ出し分の余白
│                     │
│  タイトル            │  font-size:15px 2行クランプ
│  会社名リンク        │  font-size:12px
│                     │
│  勤務地 | 勤務形態   │  font-size:12px
│                     │
│  タグ群（ピル）      │  font-size:10px
│                     │
│  キャッチコピー      │  font-size:12px 2行クランプ
│                     │
├─────────────────────┤  border-top (auto push下)
│  [職種バッジ][面談]  │
│  年収 12px          │
│                右→  │  「話を聞きに行く →」
└─────────────────────┘
  padding: 0 / border-radius: 18px
  box-shadow あり
  ブックマーク: position:absolute top:10 right:10
```

**グリッド列数**: デスクトップ3列（`repeat(3,1fr)`）/ タブレット2列 / モバイル非表示  
**グリッドgap**: 14px  
**1画面の件数**: 3列 × 約4行 = 最大12件だが、カード高さ280〜320pxのためビューポート(800px)に入るのは約3行=**9件程度**

---

### JobListCard（リスト用・横型）の構造

```
┌────────────────────────────────────────────────────────────────────┐
│ [ロゴ48px] | [flex:1 縦積み]                  | [bookmark絶対配置] │
│            │ Row1: タイトル（16px, 1行truncate）|                   │
│            │ Row2: 会社名・ブランド・フェーズ・場所・勤務形態・雇用形態│
│            │ Row3: 年収（12px green）                               │
│            │ Row4: キャッチコピー（12px, 1行, mobile-hide）         │
│            │ Row5: 先輩strip（あれば）                               │
│            │ Row6: 職種バッジ・面談バッジ・応募済み ... 詳細を見る→  │
└────────────────────────────────────────────────────────────────────┘
  padding: 12px 44px 12px 14px （右44px=ブックマーク用スペース）
  border-radius: 12px
  gap（行間）: 4px
  リスト全体gap: 6px
```

**推定カード高さ**:
- 先輩stripなし: `12(top) + 20(title) + 20(row2) + 18(salary) + 18(catch) + 24(tags) + 12(bottom) ≒ 124px`
- 先輩stripあり: `+ 約44px ≒ 168px`
- リスト6pxgap込みで、ビューポート800px → **約5〜6件表示**

---

### なぜ右半分が空白になるか（JobCard）

`JobCard` は縦型（`flexDirection:"column"`）なので、全要素が縦積みで **カード幅に収まっている**。フッター行に `justifyContent:"space-between"` があるが、左の年収と右の「話を聞きに行く」の間のコンテンツは何もない。

→ **右半分が空白ではなく、縦型カードなのでカード幅全体を使っているが、フッターの `justify:space-between` で年収が左・CTAが右に孤立して見える**。

`JobListCard` では `flex:1` の中央カラムに全情報を縦積みしており、**右サイドに独立した情報区画がない**。年収もRow3として中央カラム内に置かれているため、視覚的に「左半分に情報が固まって右側が空白」に見える（ブックマークボタンが `position:absolute right:10` に単独配置されているだけ）。

## 2. コンパクト横展開の再設計案

### コンセプト: 3ゾーン水平レイアウト

```
┌──────────────────────────────────────────────────────────────────────┐
│ [ロゴ] │ [中央: タイトル + メタ情報]         │ [右: 年収 + アクション] │
│ 40px   │  flex: 1                            │  w: 130px              │
└──────────────────────────────────────────────────────────────────────┘
  padding: 12px 14px
  gap: 12px
  border-radius: 10px
  推定高さ: 72〜80px（先輩stripなし）/ 100〜108px（先輩stripあり）
```

#### 詳細レイアウト

```
┌─────┬───────────────────────────────────────┬───────────────────┐
│ [L] │ タイトル（14px bold, 1行truncate）       │ 400〜800万円      │
│ 40px│ 会社名・フェーズ · 場所 · 勤務形態（12px）│ （15px green bold)│
│     │ キャッチ（12px muted, 1行, 省略可能）    │ 年収              │
│     │ [職種バッジ][面談受付中]                 │ [♥] 詳細 →       │
└─────┴───────────────────────────────────────┴───────────────────┘
```

#### 各ゾーン詳細

**左ゾーン（ロゴ）**
- `CompanyLogo size={40} borderRadius={8}`
- 縦センタリング (`align-self: center`)
- 現状の48px → 40pxに縮小（カード高さ圧縮のため）

**中央ゾーン（flex:1）**
- **L1: タイトル** — `fontSize:14px fontWeight:700` 1行truncate（現状16px→14px）
- **L2: メタ情報** — 会社名(12px royal) + フェーズバッジ + ` · ` 区切りで場所・勤務形態を1行に流す（現状のRow2そのまま、すでに実装済み）
- **L3: キャッチコピー** — `fontSize:11px color:var(--ink-mute)` 1行truncate（モバイル非表示維持）
- **L4: バッジ行** — 職種バッジ + 面談受付中バッジのみ（先輩stripは別扱い）

**右ゾーン（w:130px, flex-shrink:0）**
- 上: 年収 `fontSize:15px fontWeight:700 color:var(--success)` + 「万円〜万円」（Interフォント）
- 右側に「年収」ラベル `fontSize:10px color:var(--ink-mute)`
- 下: ブックマーク(♥)ボタン + 「詳細 →」テキストリンク（横並び）
- ブックマークは `position:absolute` から **右ゾーン内のflex要素** に移動
- 全体: `display:flex flexDirection:column alignItems:flex-end justifyContent:center gap:6px`

#### 先輩strip

先輩がいる場合のみ、中央ゾーンのL4バッジ行と同じ行に小さく表示、またはL4の下に1行追加。

```
[生さん・小松さんが先輩にいます 話を聞く →]  ← 現状そのままでも良い（高さ追加は約30px）
```

---

### カード全体クリック遷移

`/people` で実装したのと同じパターン:
- `<Link href={/jobs/${job.id}}>` でカード全体をラップ（現状の `job-list-card-link` も同様の実装）
- **ブックマークボタンは `onClick: e.stopPropagation()`** — 現状も同じパターン、変更なし
- **会社名クリックは `role="link" tabIndex={0}` + `onClick: e.stopPropagation(); router.push(/companies/...)`** — 現状も同じ、変更なし

→ **現状の JobListCard はすでにカード全体クリックが実装されている**（`<Link>` でラップ）。変更不要。

---

### 年収の見せ方

右ゾーンに独立させることで、サイズを大きく・目立たせられる:
- 年収あり: `15px fontWeight:700 color:var(--success)` + `10px` の「年収」ラベル
- 年収応相談: `11px color:var(--ink-mute)` でグレーアウト（右ゾーン上段に）

現状 Row3 で中央カラム内に小さく置いていた年収を右ゾーンに独立させることで、「比較しやすさ」が格段に上がる（LinkedIn型の強み）。

### 1画面の件数見積もり

| パターン | カード高さ | gap | 800pxビューポートで | 1000pxで |
|---|---|---|---|---|
| 現状 JobListCard（先輩なし） | ~124px | 6px | **5件** | **6件** |
| 現状 JobListCard（先輩あり） | ~168px | 6px | **4件** | **5件** |
| 新デザイン（先輩なし） | **~76px** | 6px | **9件** | **11件** |
| 新デザイン（先輩あり） | **~108px** | 6px | **6件** | **8件** |

→ **先輩strip のない求人で約2倍の表示密度** を実現。先輩ありでも1.5倍。

---

### 「窮屈でない」バランスの保ち方

- カード内padding: `12px 14px`（現状と同じ）— 絶対的な余白は維持
- 行間gap: `4px`（現状と同じ）— 中央カラム内の行間は変えない
- タイトル `fontSize:14px`（現状16px→-2px）— 1px単位の差だが全体の印象が変わる
- 境界線: `1px solid var(--line)` ボーダーのみ（box-shadowは薄め）
- ホバー時: `box-shadow:0 2px 8px rgba(0,35,102,0.08)` + `background:var(--bg-tint)` で浮き感を出す
- ロゴ左端 + テキスト中央 + 年収右端という3点の重心バランスで「整然感」を出す

## 3. モバイル対応

### 方針: 2ゾーン縦積み（右ゾーンを下に移動）

```
モバイル（<768px）:
┌──────────────────────────────────┐
│ [ロゴ 36px] タイトル（bold, 13px）│  Row1（flex横）
│ 会社名 · フェーズ · 場所         │  Row2
│ 年収（green 14px bold）          │  Row3
│ [職種バッジ][面談受付中] 詳細 →  │  Row4（justifyContent:space-between）
└──────────────────────────────────┘
  ブックマークは position:absolute top:8 right:8 に戻す
  キャッチコピー: 非表示（job-list-mobile-hide 維持）
  右ゾーンの「詳細 →」はRow4右端に移動
```

**CSS実装方針**: `@media (max-width: 767px)` で右ゾーンを `display:none` にしつつ、年収・詳細CTAを中央ゾーン下部に展開。または flex-wrap で自然に縦積みにする。

## 4. 既存機能への影響とリスク

| 機能 | 影響 | 対応方針 |
|---|---|---|
| 検索・フィルタ・並び替え | なし | カードUIのみ変更 |
| お気に入り（ブックマーク） | ボタン位置が変わる | 右ゾーン内に移動、stopPropagation維持 |
| ホバープレビューパネル | なし（`onHover` prop はそのまま） | JobListCard の `onMouseEnter/Leave` を新カードでも呼ぶ |
| グリッドビュー（JobCard） | 別コンポーネントなので独立 | 今回はリスト用のみ変更（JobCardは後回し or 廃止検討） |
| 先輩strip | カード高さが変わる | 先輩ありカードはやや高くなる（許容範囲） |
| 進捗バー（N/M件表示） | なし | |
| グルーピング通知チップ | なし | |
| モバイル表示 | 要再確認 | `job-list-mobile-hide` クラスは維持 |

**リスク**:
- **ブックマークボタン位置変更**: `position:absolute` → `flex要素` に変わるので、クリック領域・z-indexの調整が必要
- **右ゾーン幅の固定**: 年収文字列が長い場合（例: 「1,200〜2,000万円」）に右ゾーンが崩れる可能性 → `overflow:hidden text-overflow:ellipsis` または幅調整

## 5. 実装の分割案

### Phase A: `JobListCard` の3ゾーン化（メイン）
- 右ゾーン（w:130px）を追加
- 年収を右ゾーンに移動
- ブックマークボタンを右ゾーン内に移動（position:absolute廃止）
- タイトル fontSize 16→14px
- ロゴ size 48→40px
- モバイル対応 CSS
- `npm run build` + 目視確認

### Phase B: `JobCard`（グリッド用）の廃止 or 簡略化（後日）
- リスト表示で十分な情報密度が出れば、グリッドビューは廃止も検討
- または JobCard も同じ3ゾーン化（縦→横変換）

---

## 6. 実装時の注意点

1. **ブックマーク stopPropagation**: 右ゾーンの `<button>` に必ず `e.stopPropagation()` を付ける（カード全体が `<Link>` でラップされているため）
2. **会社名クリック**: `role="link"` の span も `e.stopPropagation()` + `router.push` のまま維持（Link内のネストリンク問題の既存対処）
3. **ホバープレビュー**: `onHover?.(job)` を `onMouseEnter` で呼ぶ。現状は `<Link>` の `onMouseEnter` に付いているため、新カードでも最外ラッパー（`<div style={{position:"relative"}}>`）ではなく `<Link>` 要素に付ける
4. **先輩strip のクリック**: `onClick: e.stopPropagation(); router.push(...)` のまま維持
5. **`isApplied` / `alumni` propは不変**: JobListCardのprop signatureは変えない
