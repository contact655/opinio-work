### 右側（新規: 候補者一覧プレビュー）

#### 設計判断: バッジ + コメント両方採用

メンター要素の見せ方を「バッジだけ」「コメントだけ」「両方」で検討し、
**両方（バッジ + コメント）** を採用。理由:

- バッジのみ: 目立つが「メンターが何をしたか」が伝わらない
- コメントのみ: 読ませる必要があり、ファーストビューには重い
- **両方**: バッジで「面談済み」の事実を瞬時に伝え、コメントで「メンターの判断」を補強
  → 「軽い応募がない」という構造訴求に直結する

#### 候補者カードの設計

```
┌─────────────────────────────────────────────┐
│ [M] 山田 健太郎                  [★ 面談済] │
│     フィールドセールス · 5年 · SmartHR 出身 │
│ [SaaS営業] [エンタープライズ]               │
│ 「SaaS商談の引き出しが多く、即戦力...」     │
└─────────────────────────────────────────────┘
```

- アバター: 名前イニシャル + 企業カラーグラデーション
- 「★ 面談済」バッジ: `success` green (var(--success-soft) / var(--success))
- メンターコメント: italic + left border (var(--royal-100))

#### 出身企業の表記方法と判断理由

**「実名表記」を採用**（SmartHR / Salesforce Japan / Money Forward）

理由:
- 求職者向け LP が実名（LayerX, HubSpot, Ubie）で運用中（MOCK_JOBS）
- 同方針に準じることで「IT/SaaS 大手出身」という即戦力感を視覚的に強調
- 架空の候補者カードであることを「※ 架空の候補者イメージです」で明示しているため
- ロゴ画像は使用せずテキスト表記のみ → 許諾不要の範囲

**採用しなかった案**: 「大手SaaS出身」など業界カテゴリ表記
→ 漠然としすぎてリアリティが薄く、差別化訴求に弱い

#### フローティングバッジ

カード右下に吹き出し的に配置:
```
🤝 全員メンター面談済み
   本気度確認 · ミスマッチ防止
```

求職者 LP の「佐藤さん（元HubSpot）」フローティングと対になる設計。
