## ⚠️ 計測上の注意（次に測る人へ）

**`getBoundingClientRect().top` と `offsetTop` が、同じ要素で最大 16px 食い違った。**
`scrollY = 0` / `scrollingElement.scrollTop = 0` / `visualViewport.offsetTop = 0` を確かめたうえで、
sticky な要素（検索帯）と本文の rect だけが **+16px** ずれた（並び替え帯はずれない）。
Browser パネルのビューポート・エミュレーションの副作用と見ている。**原因は未特定。**

→ **上部の高さを測るときは `offsetTop` を使うこと。**

```js
const off = el => { let t = 0, e = el; while (e) { t += e.offsetTop; e = e.offsetParent; } return t; };
```
