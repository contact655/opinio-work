## 2つの軸の置き場所

| | 相性のものさし | 入社後レビュー |
|---|---|---|

## ⚠️ 同じキーで中身が違うもの

| キー | 相性のものさし（1 ↔ 5） | 入社後レビュー（0 ↔ 4） | 違い |
|---|---|---|---|
| `work_style` | 自分で考えて動く ↔ 型や仕組みに沿って動く | 決まったやり方に沿って進める ↔ やり方は自分で決める | **向きが逆**（「自分で」が左と右に分かれる） |
| `decision` | スピード重視 ↔ 合意形成を重視 | 上が決めて降りてくる ↔ 現場で話し合って決める | **意味が違う**（速さの軸と、決める人の軸） |

そのほかは片方にしか無い。相性のものさしだけ: `phase` / `result` / `customer` / `growth`。入社後レビューだけ: `onboarding` / `evaluation` / `change` / `closeness`。

## ⚠️★統一するときの注意

- **キーが同じことだけを根拠に突き合わせないこと。** `work_style` をそのまま結ぶと、本人の好みと会社の実態が**逆向きに**比べられる（「自分で考えたい人」に「型に沿う会社」が合うと出る）。`decision` は比べる意味自体が無い。
- 突き合わせるなら、**軸ごとに「同じ問いか」「向きは同じか」を人が確かめた対応表**を作り、その表を通す。
- 値の幅も違う（1〜5 と 0〜4）。換算もその対応表に書く。
- どちらかのキーを付け替える場合、既に保存された回答（`ow_fit_axis_answers.axis_key` は CHECK なし・`axes_version` あり ／ `ow_workplace_review_axes.axis_key` はマスタへの FK）の扱いを先に決める。
