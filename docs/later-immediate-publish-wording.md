## いまの仕組み（書き換えの前提）

| 場面 | 何が起きるか |
|---|---|
| 企業ページが公開中（listed）・17項目がそろっている・禁止表現なし | 「公開する」で**すぐ公開** |
| 企業ページが公開中でない | 公開できない（「企業ページの公開後に公開できます」）。⚠️ 企業ページの初回公開は運営が行う |
| 禁止表現に当たる | 「運営確認中」。どの表現かを企業に出す。直して公開し直せば、該当が無くなっていればすぐ公開 |
| 運営が停止した求人 | 理由を企業にメールと求人管理の画面で知らせる。直して「公開する」→ 運営確認中 → 運営が戻す |

## 書き換え不要（確認済み）

- 掲載規約 第7条1項「当社所定の方法により求人情報を掲載することができます」… 中立
- 掲載規約 第7条4項「事前の通知なく…修正、非表示または削除を行うことができます」… 公開後の停止をそのまま含む。
  停止の理由を通知する運用は規約より手厚い（書き足すかは任意）
- 掲載規約 第3条3項 … 企業の**登録**の承認の話で、求人ではない
