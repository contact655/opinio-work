# 人材紹介利用規約を OPINIO から外す（★掲示するまで当てない）

**決定（2026-09-05 / 柴さん）**

> OPINIO は**月額プラン**。LinkedIn / Wantedly / YOUTRUST に近いモデル。
> **会社（株式会社Opinio）は人材紹介事業を行っているが、OPINIO というプロダクトには不要。**

したがって `/terms/placement`（人材紹介利用規約・成功報酬15%）は
**このプロダクトの規約から外す。**

⚠️ **会社の人材紹介事業そのものを畳む話ではない。** 有料職業紹介事業の許可
   （13-ユ-316441）も `legal-agency.md`（職安法32条の13の明示）も `ow_placements` /
   `/admin/placements` も**そのまま残す**。外すのは「OPINIO を使う企業に
   成功報酬の規約を課す」という建て付けだけ。

## ★まだやっていないこと（掲示が要る）

### ① なぜ即座に当てないか

`/terms/placement` は**いまも形式上有効**。第1条2項に**みなし同意条項**がある。

> 2. 利用企業は、**本サービスの利用を開始した時点で**、本規約の全ての内容に
>    同意したものとみなされます。

明示的な同意記録（`ow_terms_agreements` の `terms_type='placement'`）は
**0件**だが、この条項があるので「誰も拘束されていない」とは言えない。

⚠️ **したがって、掲示が終わるまで `/terms/placement` のページとリンクは残す。**
   有効な規約を辿れなくするのは、透明性の面でまずい。

### ② 掲示の要件

| | |
|---|---|
| 根拠 | 人材紹介利用規約 **第24条2項** ／ 掲載利用規約 **第21条2項** |
| 方法 | **本サービス上に掲示**（⚠️ 求職者向けと違い**メール通知は不要**） |
| 期間 | **効力発生日の30日前まで** |

⚠️ 今回は**義務を無くす方向のみ**なので第24条1項1号「利用企業の一般の利益に
   適合する場合」に当たるが、**2項の掲示要件は形式上かかる**。省略しない。

⚠️ **9/27（求職者向け規約の改定日）には乗せられない。** 8/28 までの掲示が必要で、
   既に過ぎている。**掲示日 + 30日**が最短。

## ④ 掲示の文面（案・未確定）

```markdown
## ⚠️ 規約改定のお知らせ（20XX年XX月XX日 効力発生）

**掲示日：20XX年XX月XX日　／　効力発生日：20XX年XX月XX日**

「OPINIO 人材紹介利用規約（企業向け）」は、効力発生日をもって
**本サービス（OPINIO）には適用されないもの**とします。

### 変更の理由

OPINIO は、職業安定法第4条第6項に定める**募集情報等提供**に該当する
サービスです（掲載利用規約 第6条第1項）。当社は本サービスにおいて
雇用関係の成立のあっせんを行っておらず、**本サービスの利用に関して
成功報酬が発生することはありません。**

これまで、人材紹介利用規約 第10条は「スカウトの送信」または「応募」を
成功報酬の発生条件（プラットフォーム接触）として定めていましたが、
いずれも本サービスの機能であり、当社によるあっせんではありません。
実態に合わせ、**本サービスの利用を人材紹介利用規約の対象から外します。**

> **この変更により、利用企業に新たな負担が生じることはありません。**
> 本サービスの利用に関して発生する費用は、掲載利用規約 第5条に定める
> 有料プランの利用料金のみです。

### 当社の人材紹介サービスについて

当社は有料職業紹介事業者（許可番号：13-ユ-316441）として、本サービスとは
**別に**人材紹介サービスを提供しています。同サービスのご利用には**別途の
契約**が必要です（掲載利用規約 第6条第2項）。
```

⚠️ **この文面は未確定。** 掲示日・効力発生日を決めてから確定させる。
