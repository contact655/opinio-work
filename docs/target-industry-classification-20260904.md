解体する日にやること: **軸1側（業種特化）の紐づけだけを外し**、マスタを `is_active = false` にする
（物理DELETEしない）。

⚠️★**facet からは自動的に消えます。** `getBusinessDomainFacets` は
   `is_active = true` かつ `count > 0` のものだけ返すので、**2社が抜けた時点で選択肢から消えます**。

### 4-4. ★旧キーへの参照（`?industry=`）

**実測して分かったこと。ここが一番の落とし穴です。**

| キー | いまの挙動 | 解体後 |
|---|---|---|
| `?industry=vertical` | 業種特化の2社（Ubie・nCino）が出る | **0件になる** |
| `?industry=healthcare` | ⚠️ **`LEGACY_KEYS` が `healthcare → vertical` に読み替えている**ので、同じ2社が出る | **0件になる** |

⚠️★`searchCompanies` の絞り込みは `ow_business_domains.slug` で引くだけで **`is_active` を見ていません**。
   したがって「無効化しただけ」では0件になりません。**紐づけ行を消した時点で0件**になります。

**`LEGACY_KEYS` の扱い（案）**

- **いまは触らない。** `healthcare` の移し先が軸1に存在しないため。
  Ubie の新しい軸1（AI・データ）へ向けると、「ヘルスケア」で絞ったのに **AI・データの12社が出る**という誤誘導になります
- **表示フェーズで軸2の絞り込み（例 `?target=healthcare`）を作るときに、そちらへ振り替える。**
  そのとき `LEGACY_KEYS` から `healthcare` を外し、軸2側のキーに移すのが筋
- それまでの間、`?industry=healthcare` と `?industry=vertical` は **0件のページ**になります。
  ⚠️ 0件でも「該当なし」の画面は出るので壊れはしませんが、**被リンクがある場合は体験が落ちます**

⚠️ `vertical-saas` という旧キーは**どこにも存在しませんでした**（`LEGACY_KEYS` は `fintech` / `ec` / `healthcare` の3つだけ）。
