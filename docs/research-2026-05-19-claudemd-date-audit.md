## 2. `currentDate` の所在確認（最重要発見）

### git 検索結果

```bash
git log -p -S"currentDate" -- CLAUDE.md
# → 出力なし（0件）

grep -n "currentDate\|今日の日付\|Today.*date" CLAUDE.md
# → 出力なし（0件）
```

### disk 実体 vs git HEAD の比較

`tail -30 CLAUDE.md`（disk実体）と `git show HEAD:CLAUDE.md | tail -30` の出力が**完全一致**。
disk 上の CLAUDE.md にも `currentDate` セクションは存在しない。

### 結論（確定）

**`currentDate` は CLAUDE.md に存在しない。git 管理外で、Claude Code システムがランタイムに動的注入している。**

セッション開始時に system-reminder として `# currentDate / Today's date is XXXX-XX-XX` が Claude に渡されるが、この値は CLAUDE.md ファイルに書き込まれず、コミット履歴にも一切残らない。

→ **`currentDate` 注入値の時系列を git から追うことは不可能**（git 追跡対象外のため）。

## 6. 日付ズレの原因 — 確定できること / できないこと

### 確定した事実

| 事実 | 根拠 |
|------|------|
| OS クロックは 2026-05-17 を示していた | git コミット日時（05-17 で一貫）|
| `currentDate` は CLAUDE.md に存在しない | grep, disk vs git HEAD 比較 |
| `currentDate` は git 追跡不可能なランタイム注入 | ファイルに存在しないため |
| 21.md 内容に "2026-05-21" / "前回: 2026-05-20" | ファイル読み取り |
| 24.md 内容に "申し送り 2026-05-23"、commit msg に "2026-05-24" | ファイル読み取り + git show |
| ±0 / ±1日のズレは正常パターン（他の handover で実証） | 全 handover 比較 |
| +4/+7日のズレは他に類例なし | 全 handover 比較 |

### 確定できない原因（複数解釈が残る）

#### 解釈 A: `currentDate` 注入値が OS クロックと乖離していた

Claude Code が `currentDate` を計算する際、OS クロック以外のソース（例: キャッシュ、設定値、前セッションの要約）を使い、"2026-05-21" / "2026-05-24" が注入された。

**支持する間接証拠**: 他のセッションで ±1日の安定したズレが見られる（注入値がOS日時と微妙にずれることは観測済み）。  
**反証できない**。注入値は git に残らないため。

#### 解釈 B: ユーザーが会話中に日付を指定した

会話中に「今日は5/21です」等の発言があり、Claude がその日付でハンドオーバーを生成した。

**支持する証拠**: なし（git から会話内容は参照不可）。  
**否定する証拠**: なし。

#### 解釈 C: Claude が日付を推定・生成した（幻覚）

`currentDate` 注入なし or 注入値が不明確で、Claude が文脈から日付を推定し誤った値（5/21, 5/24）を出力した。

**支持する間接証拠**: 5/17 → 5/21（+4日）、5/17 → 5/24（+7日）という異常な乖離は「推測エラー」的。  
**反証できない**。

#### 解釈 D: 投機的先付けハンドオーバー（意図的未来日付）

5/17 のセッションで「次のセッションを 5/21 予定」「その次を 5/24 予定」として意図的に未来日付を付けたハンドオーバーを生成した。

**支持する証拠**: handover-2026-05-21.md が untracked（commit 忘れではなく「意図的に保留」の可能性）。  
**疑問点**: なぜ 5/24.md は commit したのに 5/21.md は commit しなかったか。

### 解釈を絞るために必要な追加事実

| 必要な情報 | 取得方法 |
|----------|---------|
| 2026-05-17 のセッション実会話ログ | `~/.claude/projects/*/` 以下の `.jsonl` ファイルを確認（実施は別途判断が必要）|
| 当時の `currentDate` 注入値 | 上記会話ログに含まれる system-reminder を確認 |
| ユーザーが「今日の日付は〜」と言ったか | 上記会話ログを検索 |

**現時点での最有力仮説**（断定ではない）:  
2026-05-17 のセッションで Claude Code が "2026-05-21" または "2026-05-24" という日付を `currentDate` として注入した（OS クロックと乖離していた）か、あるいは Claude が文脈から日付を誤推定した。いずれも git 証拠では確定不可。  

会話ログ（`~/.claude/projects/` 以下 `.jsonl`）の system_reminder フィールドを確認すれば、当時の `currentDate` 注入値が判明する可能性が高い。ただしログの閲覧は柴さんの判断事項（プライバシー・サイズ考慮）。
