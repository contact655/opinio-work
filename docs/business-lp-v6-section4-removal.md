# 実装依頼: /business LP v6 セクション4 の数字削除

## 背景・思想

Opinio Work の戦略上の **北極星**:

> /businessLP・利用規約ともに「人材紹介」表現・数字を完全排除。
> 媒体の実数（登録ユーザー数等）が貯まってから出す方針。

現状の /business LP v6 のセクション4 に **早すぎる数字** が掲載されており、これを削除する必要がある。

## なぜ削除するか（思想的根拠）

1. **媒体としての実数がまだ少ない**: 公開済み企業31社、ユーザー登録数も発展途上。LinkedIn 型「広く掲載、絞って収益化」戦略上、数字を出すのは媒体の実数が貯まってからにしたい
2. **人材紹介事業の数字を媒体側に持ち込まない**: 株式会社 Opinio の人材紹介事業（120社+取引先、200名+候補者など）の実績数字は別事業のもの。Opinio Work（媒体）の数字として混在させない
3. **「キャリア意思決定インフラ」ポジショニング**: 数字より思想・コンセプトで勝負するフェーズ

## スコープ

### 対象ファイル

`/business` ページの LP（v6）のうち、**セクション4 に該当する箇所**。

実装側で以下を特定してください:
1. `/business` ルートのページコンポーネントの場所
2. v6 とされている LP の構造（セクション分割の方法）
3. 「セクション4」が具体的にどのセクションか（コード内のコメント、セクション ID、見出しなどから判定）

### 「数字」の定義

**削除対象**:
- 具体的な実績数値（例: 「導入企業120社」「採用成功○○名」「平均○日でマッチング」「採用成功率○○%」等）
- パーセンテージで表現された実績（例: 「離職率0%」「面談実施率○○%」）
- 期間や規模を示す数値で、実績や成果を示唆するもの

**削除しない**:
- 価格・料金体系の数値（成果報酬「年収30〜35%」など、サービス仕様として必要なもの）
- 機能説明上の数値（例: 「8ジャンル分類」「3ステップで完了」のようなプロセス説明）
- ジャンル数や項目数など、媒体の構造を説明するもの

判断に迷う数値があれば、削除前に「これは削除対象か？」とコメントで列挙してください。

### 削除の方法

数字を削除した結果、文章が破綻しないように調整:
- 数字を削除しただけで文意が通る場合 → 数字だけ削除
- 数字を削除すると文章が成立しない場合 → 該当の文・段落・要素を丸ごと削除
- セクション全体が数字に依存していて削除すると空になる場合 → セクション全体を削除（要事前報告）

## やらないこと

- セクション4 以外のセクションには触らない（他セクションにも数字があったとしても、本依頼の対象外）
- 構造的な改修（レイアウト変更、配色変更等）は一切しない
- 新規セクションの追加もしない
- 利用規約・プライバシーポリシーのファイルには触らない（別件）

## 受け入れ基準

1. /business LP のセクション4 から実績数値が削除されている
2. 削除後も文章・レイアウトが破綻していない
3. セクション4 以外に影響なし
4. `npm run build` 通過
5. `git push origin main` までセット
6. Vercel デプロイ確認

## 完了後の報告事項

1. コミット hash
2. セクション4 の具体的な内容（どんなセクションか、何を訴求していたか）
3. 削除した数字の一覧
4. 削除後の文章への影響（軽微 / 文構造変更あり / セクション縮小）
5. 判断に迷った数字があれば、その判断理由

## 重要: 既存運用ルールの遵守

- `npm run build` 必須
- `git push origin main` 必ず実行（commit hash で Vercel deployments 目視確認）
