# Phase ν-6 レスポンシブ対応チェックリスト

Phase ν-6 で実装したコンポーネントとページのレスポンシブ対応状況を記録。
ν-6 段階 5 では実機確認・修正は行わない（チェックリスト化のみ）。
実機確認と修正は ν-7 以降で実施する。

## 対象範囲

### ページ
- /mypage（コンパクトプロフィールカード + ダッシュボード要素）
- /profile/edit（設定ページ - ν-6 段階 5 で簡素化）

### コンポーネント
- UserProfileCard
- InlineEditableField
- InlineEditableSection
- CareerHistoryEditor
- ConfirmDialog
- Toast

## チェック項目

### モバイル（375px 幅、iPhone SE 想定）

#### /mypage
- [ ] ヘッダーのナビゲーション（企業を見る / 求人を探す / メンター / 記事 / 発信）が
  折り返しなく表示、またはハンバーガーメニュー化
- [ ] サイドナビ（ダッシュボード / カジュアル面談 / メンター相談 など）が
  画面幅に収まる、または上部に移動
- [ ] MOCK 切り替えバナーが画面幅に収まる
- [ ] プロフィールカードのアバター（80px 想定）と氏名が適切に配置
- [ ] 名前 / 所在地 / 年齢層 / 自己紹介 / 想い (future_aspirations) の
  各 InlineEditableField が画面幅に収まる
- [ ] 編集モード時のフォームが画面幅に収まる（特に textarea のリサイズ）
- [ ] CareerHistoryEditor の各 stint カードが縦積みで適切に表示
- [ ] CareerHistoryEditor の編集フォーム（会社名 / 役職カテゴリ / 期間 /
  この時期に目指していたこと / 職務内容）が縦積みで表示
- [ ] 期間入力（type="month"）の input がモバイル Safari で正常表示
- [ ] 「+ 経歴を追加」ボタンが押しやすい高さ（44px 以上推奨）
- [ ] SNS リンクの 3 フィールド一括編集（X / LinkedIn / note）が縦積みで表示
- [ ] ConfirmDialog（削除確認）が画面中央に表示、ボタンが押しやすい
- [ ] Toast（職歴を追加 / 更新 / 削除しました）の表示位置が適切

#### /profile/edit（設定ページ）
- [ ] 左サイドバーがハンバーガーメニュー化される or 上部に移動
- [ ] プロフィール画像アップロード UI が画面幅に収まる
- [ ] アカウント設定の各項目（メール / パスワード変更 / 公開設定 /
  アカウント削除）が画面幅に収まる

### タブレット（768px 幅、iPad 縦想定）

- [ ] /mypage のレイアウトが破綻しない
- [ ] サイドナビが適切に表示される
- [ ] プロフィールカードの 2 カラム表示（アバター + 情報）が維持される
- [ ] CareerHistoryEditor のカードが横幅を活用した表示
- [ ] /profile/edit のサイドバーが従来通り表示される

### デスクトップ（1280px+）

- [ ] 既存実装で問題なし（ν-6 段階 0〜4 で確認済み）

## モバイル特有の注意点

- 編集モード時にキーボード表示で画面が縮む際の挙動
- iOS Safari の `<input type="month">` の表示崩れ
- スクロール中のホバー状態の扱い（hover で出る編集ボタンが
  タッチデバイスでどう見えるか）
- ConfirmDialog のバックドロップタップで閉じる動作

## ν-7 対応予定

ν-6 段階 5 では以下を実施しない:
- 実機（モバイル / タブレット / デスクトップ）での動作確認
- 崩れ箇所の修正
- メディアクエリの追加
- レスポンシブ用 CSS 変数の整備

ν-7 で別途タスクとして対応する。
