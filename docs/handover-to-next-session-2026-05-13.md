## 🌟 今日確定した4つの北極星（最重要）

### 1. ビジネスモデル
> **「掲載無料で入社決定時の成果報酬でマネタイズ」**

- 完全無料、収益は人材紹介事業（成功報酬制、年収の30〜35%）
- Wantedly/Green 型の SaaS 月額課金は採用しない
- 月額課金/広告/上位表示課金/求職者課金 → 全て NO
- マッチング促進機能 → 全て無料

### 2. ターゲット戦略
> **LinkedIn 型「広く掲載、絞って収益化」**

- 掲載：キャリアに関わる全ての組織（IT/SaaS、スタートアップ、個人事業主、副業オーナー、NPO、士業など）
- 収益化：IT/SaaS 中堅以上で人材紹介で売上が立つ層
- 短期：まず IT/SaaS に集中
- 長期：キャリアに関わる全ての組織

### 3. 登録ポリシー
> **個人ドメインも許可、Opinio 承認制で品質担保**

- gmail.com 等の個人ドメインも登録可
- ドメイン自動拒否はしない
- スパム/偽組織は admin（Hisato）が手動却下

### 4. ロール設計
> **第一層：admin / candidate の2種類 + 第二層：企業との関係性属性**

- ow_user_roles：admin（運営）または candidate（一般）
- ow_company_admins：admin/member の2段階
- ow_experiences：在籍歴
- 1ユーザーが複数企業の管理権限と在籍歴を持てる
- UI 通称：「企業管理者」「企業メンバー」「現役社員」「OB-OG」
