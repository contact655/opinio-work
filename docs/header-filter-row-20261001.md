## ★決めてほしいこと（3つ）

### (A) `/people` のキーワードを URL に入れるか
いまは入っていない。仕様の「URLから復元してチップ表示」を `/people` でも成立させるには

- **A-1**: `/people` にも `?q=` を足す（4ページで挙動が揃う。リロードで残り共有もできる）

### (B) 375px でどう畳むか
いま4要素＋件数が375pxに全部載っていて、**検索窓が173pxに潰れている**。
ボタン化すると幅は空くが、それでも「一覧内を検索 / 詳細検索 / 並び替え / 一覧・詳細 / 件数」の

- **B-3**: いまのまま全部載せる（ボタン化で幅が空くぶん、潰れは解消する）

1段目を作り直すときに**残す**でよいか（読み上げ用なので残す前提で進める）。

### ⚠️★ 🔍ボタンは消していない（仕様からの逸脱・理由）

指示は「右端の🔍アイコンボタンは削除する」だったが、**1024px 未満では残した。**
**モバイルのタブバーにも引き出しにも検索は無く、これが唯一の `/search` への入口**だから。
消すと狭い画面から横断検索が丸ごと無くなる。1024px 以上では出していない。

### ⚠️★ 元からあった不具合を1つ直した（`display` のインライン指定）

🔍ボタンは `className="hidden md:flex"` なのに **インラインで `display: "flex"`** を持っており、
インラインが勝つので **`hidden` が一度も効いていなかった**（本番の HTML でも確認）。
＝ **モバイルにも🔍は出ていた。** `lg:hidden` に替えたときに表に出たので、
インラインの `display` を外してクラスに任せる形にした（ui-debugging ②）。
