## 2. 訴求の核（北極星）

### 2.1 ポジショニング

**「採用ミスマッチを構造的に防ぐ、IT/SaaS 業界特化の求人媒体」**

### 2.2 3つの差別化軸

| 軸 | 訴求 |
|---|---|
| **コスト** | 掲載無料、入社決定時のみ成果報酬 |
| **メンター制度** | 候補者がメンターと面談済み、本気度の高い応募のみ届く |
| **ユーザーの質** | IT 業界職経ありユーザーが中心、即戦力人材 |

### 2.3 競合とのポジション

- Wantedly / Green: 媒体型、コストは類似だが「気軽な応募」が多い
- Bizreach / LinkedIn: ハイクラス、コスト高い、スカウト主体
- ラプラス / Forkwell: エンジニア特化、業界がより狭い
- **Opinio Work**: IT/SaaS 業界 × メンター介在 × 即戦力中心 ← **独自カテゴリ**

### 3.2 セクション2: 料金比較表

**変更なし**（v1 のまま）

| サービス | 月額費用 | 成果報酬 | 求人掲載 | コスト感 |
|---|---|---|---|---|
| **Opinio Work** | **無料** | **年収30〜35%** | **無料** | **入社決定時のみ** |
| 他社例 A（スカウト型） | 約20万円〜 | なし | 含まれる | 採用ゼロでも月額発生 |
| 他社例 B（媒体型） | 媒体課金 | なし | 別途課金 | 掲載期間中常時発生 |
| 他社例 C（紹介型） | 無料 | 年収30〜35% | 別途課金 | 入社決定時のみ |

訴求コピー:
```
他社が「掲載で稼ぐ」のに対し、
Opinio は「採用が成功したときだけ」収益を得ます。

だから、企業も求職者も
質の高いマッチングしか追求できない構造。
```

### 3.4 セクション4: 「なぜミスマッチが起きないのか」【新規 / 戦略修正の核心】

**v1 の「人材紹介事業の実績」を全面置き換え**

**コピー**:
```
なぜ採用ミスマッチが起きないのか？
```

**サブセクション1: メンター制度**
```
▼ メンターが間に立つから

Opinio には、IT 業界で経験を積んだメンターが在籍しています。
候補者は応募前に必ずメンターと面談し、
企業の文化や働き方、キャリアの方向性を擦り合わせた上で
応募してきます。

「軽い気持ちでの応募」がなく、
企業側にとっても「本気度の高い候補者」だけが届く構造です。
```

**サブセクション2: ユーザー層の質**
```
▼ IT 業界職経ありユーザーが中心

Opinio に登録しているユーザーの大多数が、
IT 業界で実務経験を持つ即戦力人材です。

業界知識ゼロから教育する必要がなく、
入社後すぐに戦力として活躍できる人材と出会えます。
```

**実績の数字**（人材紹介を出さずに表現）:
```
Opinio が選ばれる理由

[ 120社+ ] IT/SaaS 企業が活用中
[ 200名+ ] のキャリア意思決定をサポート
[ 99%+  ] 早期離職率を業界平均より大幅に下回る※

※自社調べ
```

**注意**: 「人材紹介」「キャリアコンサルタント国家資格」「ICF 国際コーチング認定」などの記述は**全て削除**。

### 3.7 セクション7: FAQ（修正版）

**Q1**:
```
Q. 本当に掲載は無料ですか？
A. はい、月額費用や広告費は一切いただきません。
   求人公開、スカウト、面談まで全て無料でご利用いただけます。
```

**Q2**:
```
Q. 成果報酬の発生条件は？
A. 候補者の入社が確定した時点で、内定後の年収の30〜35%を
   ご請求します。それまでは一切請求が発生しません。
```

**Q3（修正）**:
```
Q. 自社で採用したい場合は？
A. 求人公開、スカウト、面談まで全て無料でご利用いただけます。
   自社の採用力で完結する企業様にも、
   無料の掲載基盤としてご活用いただけます。
```
※v1 にあった「人材紹介サービスのご利用は任意です」は**削除**

**Q4**:
```
Q. 営業電話はかかってきますか？
A. ございません。
   ご質問やご相談はサイト内のフォーム、または
   メール（contact@opinio.co.jp）からのみ承ります。
```

**Q5**:
```
Q. どのような業界に対応していますか？
A. 現在は IT/SaaS 業界に特化して運営しています。
   将来的には他業界への展開も予定していますが、
   現時点では IT/SaaS 業界の即戦力人材採用に最適化されています。
```

**Q6**:
```
Q. 登録に審査はありますか？
A. ございません。セルフサーブ型で、登録後すぐに
   求人を公開できます。
```

**Q7（新規追加）**:
```
Q. メンターとはどんな存在ですか？
A. IT 業界で経験を積んだプロフェッショナルです。
   候補者の方々は応募前にメンターと面談し、
   キャリアの方向性や企業選びについてアドバイスを受けます。
   これにより「本気度の高い応募」だけが企業に届きます。
```

## 4. ヘッダーの修正（重要）

### 4.1 現状の問題

`/business` ページが JobseekerHeader を使っており、求職者向けナビゲーション（「企業を見る」「求人を探す」「メンター」「記事」「発信」）が表示される。**企業向け LP なのに求職者向けメニュー**という矛盾。

### 4.2 修正方針

**新しいコンポーネント `BusinessHeader.tsx` を作成**し、`/business` ページで使用する。

### 4.3 新ヘッダーの構成

```
[Opinio Business]  サービス | 料金 | 実績 | FAQ  | 個人の方へ →  ログイン  [企業を新規登録]
```

**詳細**:

| 要素 | 内容 |
|---|---|
| ロゴ | 「Opinio」+ 小さく「Business」サブテキスト |
| サービス | LP 内アンカー（#features など、セクション4「なぜミスマッチが起きないのか」へ） |
| 料金 | LP 内アンカー（セクション2 料金比較表へ） |
| 実績 | LP 内アンカー（セクション4 内の数字へ） |
| FAQ | LP 内アンカー（セクション7 へ） |
| 個人の方へ → | `/` へのリンク（求職者向け LP に戻る） |
| ログイン | `/biz/auth` へのリンク |
| 企業を新規登録 | `/biz/companies/add/new/` への CTA ボタン |

### 4.4 実装方針

- JobseekerHeader.tsx を参考に、`BusinessHeader.tsx` を新規作成
- スタイルは既存ヘッダーと統一
- モバイル対応必須
