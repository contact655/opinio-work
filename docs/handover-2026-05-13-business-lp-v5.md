## 1. 修正1: 年収30〜35%の記述を全削除

### 変更箇所

| 場所 | Before | After |
|------|--------|-------|
| STEP4 body | 「採用が決まるまで一切請求なし。年収の30〜35%。」 | 「採用が決まるまで一切請求なし。シンプルな料金体系でわかりやすい。」 |
| FAQ Q2 answer | 「候補者の入社が確定した時点で、内定後の年収の30〜35%をご請求します。…」 | 「候補者の入社が確定した時点でご請求します。それまでは一切請求が発生しません。シンプルな料金体系です。詳細はお問い合わせください。」 |
| 比較表（自動消滅） | 「年収 30〜35%」行（Opinio行 + 他社例C行） | 修正2で比較表ごと削除 |

### 判断理由

景品表示法・競合他社への言及リスクを避けるため、具体的な%を外し
「詳細はお問い合わせください」で商談誘導する形に変更。

## 2. 修正2: Point1 料金比較表の完全削除

### 削除した要素

- `<table>` ブロック全体（横スクロール付き比較表）
  - ヘッダー行: サービス / 月額費用 / 求人掲載 / 成果報酬 / コスト発生タイミング
  - Opinio Work 行（royal blue ハイライト）
  - 他社例A（スカウト型）/ 他社例B（媒体型）/ 他社例C（紹介型）行
- 「※ 他社例は業界一般的な…」免責注記
- Emphasis ボックス（⭐ 応募・スカウト・面談まで全て無料 等）

### 判断理由

比較表は「他社を具体的に批判している」印象を与えるリスクがあり、
またパーセンテージ削除に伴い「成果報酬」列が不明瞭になるため、
Point1全体をシンプルなコピー訴求に変更した。

## 3. 修正3: Point1/2/3 → InfraBlock 左右レイアウト

### 採用した構造

求職者 LP の `InfraBlock` パターンをそのまま踏襲。
`md:[direction:rtl]` で偶数 Point（02/MENTOR）を左右反転。

### セクション構成（新）

| # | ラベル | タイトル | 右側ビジュアル | 反転 |
|---|--------|---------|--------------|------|
| Point 1 | `01 / FREE` | 完全無料で求人掲載 | 求人作成UIモックアップ | なし |
| Point 2 | `02 / MENTOR` | メンターが間に立つ仕組み | 応募フロー4ステップ図 | あり |
| Point 3 | `03 / TALENT` | IT業界職経ありユーザーが中心 | ユーザー属性タグクラウド | なし |

### Point 1 右側: 求人作成 UI モックアップ

```
┌── 求人管理 — Opinio Work ──────────────────────┐
│ [●][●][●]                                      │
│ 職種: カスタマーサクセス（エンタープライズ）     │
│ 雇用形態: 正社員  |  勤務地: 東京（リモート可） │
│ 想定年収: 600万円 〜 900万円                    │
│                 [下書き保存] [公開する]          │
│  ✓ 掲載無料 · 件数・期間制限なし               │
└────────────────────────────────────────────────┘
```

### Point 2 右側: 応募フロー 4ステップ

```
┌──────────────────────────────────────────────┐
│  応募までの流れ                              │
│  👤 候補者が求人に興味を持つ                │
│     ↓                                        │
│  🤝 メンターと事前面談（30分）★highlight   │
│     ↓                                        │
│  ✅ メンターが「推薦」と判断                │
│     ↓                                        │
│  📨 企業へ応募が届く                        │
└──────────────────────────────────────────────┘
```

### Point 3 右側: ユーザー属性タグクラウド

- **濃色 (royal)**: SaaS営業、カスタマーサクセス
- **中色 (royal-100)**: プロダクトマネージャー、エンジニア
- **淡色 (royal-50)**: マーケター、インサイドセールス
- **枠のみ**: コンサルタント、データアナリスト、デザイナー
- 下部: IT業界実務経験 / 対象業界 の2コラム mini stats

### CheckItems 一覧

| Point | CheckItem |
|-------|-----------|
| 1 | 求人掲載・スカウト・面談まで完全無料 / 掲載件数・期間 無制限 / 採用決定まで一切請求なし / クレジットカード登録不要 |
| 2 | 「軽い気持ちの応募」がない構造 / 本気度の高い候補者だけが届く / ミスマッチを事前にフィルタリング |
| 3 | SaaS営業・CS・PMなど即戦力層が中心 / 入社後すぐに戦力として活躍できる / IT業界外の応募は自然にフィルタされる |
