## 色の役割（2026-08-23 確立）

**1つの色が2つ以上の意味を持たないようにする。** これが目的で、見た目の好みの話ではない。

| 色 | 役割 | 使う場所 |
|---|---|---|
| **オレンジ** | **カジュアル面談のみ** | 面談CTAボタン、`/people` と企業ページの「話を聞けます」バッジ |
| **濃紺（塗り）** | **主要な遷移** | 応募する、求人一覧へ、無料登録 |
| **ゴースト / テキストリンク** | その場の展開・補助操作 | 「すべて見る（残り N）」、保存、フォロー |
| **黄色背景** | **使わない** | — |
| **緑** | **金銭的にプラスの条件のみ** | 年収レンジ、確定拠出年金・退職金、SO/RSU |
| **紫** | **使わない** | — |

実体は [src/lib/utils/chipVariant.ts](../../../src/lib/utils/chipVariant.ts)。
`ChipVariant` は `neutral` | `money` の2つだけ。

⚠️ **チップに個別の色を渡せる形にしないこと。** `InfoCard` は `color` / `bg` / `border` を
   受け取るのをやめ、`variant` だけを受ける。呼び出し側で色を決められると、
   凡例の無い色分けがまた増える（実際に緑が4通りの意味で使われていた）。

⚠️ **variant を増やすときは「凡例なしで意味が伝わるか」を先に考える。**
   伝わらないなら neutral のままにして、文言で説明する。

⚠️ **同じ色分けの実装が複数あることがある。** `productStyle` は
   `companies/[id]/page.tsx` と `CustomerCasesClient.tsx` の**2箇所**にあった。
   片方だけ直すと事例カードだけ色が残る。**grep して全部直す。**

## ボタン

- **その場で展開する**ボタン → **ゴースト**（背景なし・1px の標準ボーダー・標準文字色）
- **別ページへ遷移する**ボタン → **濃紺の塗り**
- どちらも中央配置・コンパクト幅。実体は
  [ShowMoreButton](../../../src/app/(jobseeker)/companies/[id]/ShowMoreButton.tsx) の
  `variant="expand"` / `variant="navigate"`

⚠️ **2026-08-12 の「展開ボタンは濃紺塗りに統一」は 2026-08-23 に上書きした。**
   当時は「幅いっぱい / 薄い水色」の旧パターンを潰すのが目的で、
   統一先として濃紺塗りを選んでいた。その後、企業詳細1枚に濃紺のボタンが6個以上並び、
   **その大半が「開くだけ」**になったため、**主要な遷移と区別する**ようゴーストに変えた。
   幅いっぱい / 薄い水色 の旧パターンを使わない点は変わっていない。

- 展開ボタンのラベルは **`すべて見る（残り N）`** に統一する。**単位語を入れない**
  （件 / 社 / カテゴリ / 部門・チーム / グループ と5種類に増えていた）。
  総数は各セクションの見出しが出す（「23 チーム · 8 部門」など）

⚠️ **求人セクションだけは「N件すべての求人を見る」（遷移・濃紺）を残す。**
   展開ボタンは出さない。ボタンを2つ縦に並べない、という判断で、
   **残す側は遷移**（2026-08-23 に確認）。ここは一度逆に実装して戻している。

## タブ

- **選択状態は下線のみ。** 塗りを併用しない
- 件数はラベル右の**ニュートラルなバッジ**（`--line-soft` 背景）で示す。0件なら出さない

⚠️ 求人タブだけ黄色の塗りが付いており、しかもアクティブかどうかと無関係に常時出ていた。
   下線の付いたタブと同時に存在するため**選択状態が2つあるように見え**、
   塗りのほうが強いので「求人が選ばれている」と誤読されていた（2026-08-23 に解消）。

## カード

- 社員・OB/OGカードは3列グリッド固定。人数が増えても表示は切り替えない
- カードに出すのは所属企業のブランド名と職種のみ。部署の階層は出さない

## ツール表示

- 大グループ5箱（営業・マーケティング / 社内コミュニケーション / 開発・データ / AI / その他）に束ねる
- DBのカテゴリ10種は維持し、表示だけ束ねる
- グループとカテゴリが1対1のとき（AI・その他）はカード内のカテゴリ名を省略する
- **カテゴリごとの色分けはしない**（上の「色の役割」に従い neutral 固定）

## style要素

- `<style>{...}</style>` 内で子孫セレクタの `>` と引用符 `"` を使わない
  （サーバー側だけがエスケープしhydration mismatchになる）
