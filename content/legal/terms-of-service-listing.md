# OPINIO 掲載利用規約（企業向け）

**制定日：2026年8月1日**
**株式会社Opinio**

> **この規約について**
> 本規約は、2026年8月1日制定の「OPINIO 掲載・人材紹介利用規約（企業向け）」を
> 「掲載」と「人材紹介」の2本に分けたものです。
> 2026年8月21日の改定により、**本サービスの利用料金を有料プランのみとし**、
> あわせて条文番号を連番に振り直しました。
> 人材紹介サービスをご利用の場合は、別途
> [人材紹介利用規約](/terms/placement) が適用されます。

## 第1章 総則

### 第1条（目的および適用）

1. 本規約は、株式会社Opinio（以下「当社」といいます）が提供する採用支援プラットフォーム「OPINIO」（以下「本サービス」といいます）の利用に関し、当社と本サービスを利用する企業（以下「利用企業」といいます）との間の権利義務関係を定めることを目的とします。

2. 利用企業は、本サービスの利用を開始した時点で、本規約の全ての内容に同意したものとみなされます。

3. 当社は、有料職業紹介事業者（許可番号：13-ユ-316441）です。ただし、本サービスは第6条に定めるとおり募集情報等提供に該当するサービスであり、職業紹介には該当しません。

### 第2条（定義）

本規約において使用する用語の定義は、次のとおりとします。

| 用語 | 定義 |
|---|---|
| **候補者** | 本サービスに登録している求職者 |
| **求人情報** | 利用企業が本サービス上に掲載する募集に関する情報 |
| **スカウト** | 利用企業が本サービス上の機能を用いて候補者に送信するメッセージ |
| **応募** | 候補者が本サービス上の機能を用いて求人情報に応募する行為 |
| **人材紹介サービス** | 当社が本サービスとは別に提供する、雇用関係の成立のあっせんを行うサービス（エージェントサービス） |
| **有料プラン** | 第5条に定める、当社が提供する有料の追加機能または役務 |

## 第2章 本サービスの利用

### 第3条（利用登録）

1. 利用企業は、当社所定の方法により登録手続を行い、本サービスの利用を開始することができます。

2. 利用企業は、登録情報に変更が生じた場合、遅滞なく当社所定の方法により変更手続を行うものとします。

3. 当社は、利用企業が次の各号のいずれかに該当すると判断した場合、登録を承認せず、または登録後に利用を停止することができます。

   1. 登録情報に虚偽の記載があった場合
   2. 過去に本規約に違反したことがある場合
   3. 第15条に定める反社会的勢力に該当する場合
   4. その他、当社が不適当と判断した場合

### 第4条（掲載費用および料金体系）

1. **本サービスにおける求人情報の掲載は、無料とします。** 掲載期間、掲載件数、掲載職種を問わず、掲載に関する費用は発生しません。

2. **本サービスの利用に関して利用企業に発生する費用は、第5条に定める有料プランの利用料金のみとします。採用の成否および採用人数にかかわらず、成功報酬その他の費用は一切発生しません。**

3. **有料プランの利用は、利用企業の任意の申込みによるものとし、当社が利用企業の同意なく有料プランを適用することはありません。**

4. **当社が本条第1項に定める無料掲載を有料に変更する場合、当社は、効力発生日の90日前までに利用企業に対し個別に通知するものとします。** 当該通知を受けた利用企業は、効力発生日までに第17条に定める方法により本サービスの利用を終了することができ、この場合、利用企業に掲載費用は発生しません。

5. **前項の変更の効力発生日より前に掲載を開始した求人情報については、当該掲載が終了するまでの間、変更前の条件が適用されます。**

### 第5条（有料プラン）

1. 当社は、本サービスの一部の機能について、有料プランを提供することがあります。

2. 有料プランの内容、料金、支払方法および契約期間は、当社が本サービス上に表示するところによります。

3. 有料プランの利用料金は前払いとし、日割りによる計算および返金は行いません。

4. 最低契約期間は定めません。利用企業は、いつでも有料プランを解約することができます。

5. 当社が有料プランの内容または料金を利用企業に不利益に変更する場合、当社は、変更の効力発生日の30日前までに本サービス上への掲示または電子メールにより利用企業に通知します。

### 第6条（本サービスの性質）

1. 本サービスは、職業安定法第4条第6項に定める募集情報等提供に該当するサービスであり、当社は本サービスにおいて雇用関係の成立のあっせんを行いません。

2. 当社は、本サービスとは別に人材紹介サービスを提供しています。同サービスの利用には別途の契約が必要であり、本規約は適用されません。

3. 利用企業が本サービスを通じて認知した求職者を、当社の人材紹介サービスによらずに採用した場合、その人数にかかわらず、本サービスに関して利用企業に費用は発生しません。

### 第7条（求人情報の掲載）

1. 利用企業は、当社所定の方法により求人情報を掲載することができます。

2. 利用企業は、求人情報の掲載にあたり、職業安定法その他の関係法令および当社が別途定める掲載ガイドラインを遵守するものとします。

3. 利用企業は、求人情報について、次の各号を遵守しなければなりません。

   1. 虚偽の表示または誤解を生じさせる表示をしないこと（職業安定法第5条の4）
   2. 正確かつ最新の内容に保つこと。募集を終了した場合は速やかに掲載を終了すること
   3. 従事すべき業務の内容および変更の範囲、就業場所および変更の範囲、労働契約の期間、有期労働契約を更新する場合の基準を明示すること
   4. 賃金について、固定残業代を含む場合はその内訳（金額、時間数、超過分の支払）を明示すること
   5. 年齢、性別、国籍等による差別的な表示をしないこと

4. 当社は、求人情報が本規約または関係法令に違反すると判断した場合、事前の通知なく、当該求人情報の修正、非表示または削除を行うことができます。

### 第8条（禁止事項）

利用企業は、本サービスの利用にあたり、次の各号に定める行為を行ってはなりません。

1. 実在しない求人、または募集の意思のない求人を掲載する行為
2. 候補者に対し、有料サービスへの加入、商品の購入、金銭の支払等を求める行為
3. 候補者の個人情報を、採用選考の目的以外に利用する行為
4. 候補者の個人情報を、候補者の同意なく第三者に提供する行為
5. 本サービスの運営を妨害する行為
6. 当社または第三者の知的財産権、名誉、プライバシーその他の権利を侵害する行為
7. 法令または公序良俗に反する行為
8. その他、当社が不適切と判断する行為

## 第3章 個人情報

### 第9条（候補者の個人情報の取扱い）

1. 利用企業は、本サービスを通じて取得した候補者の個人情報について、個人情報の保護に関する法律、職業安定法およびこれらに基づく指針を遵守し、適正に取り扱うものとします。

2. 利用企業は、候補者の個人情報を、**採用選考の目的のみに利用**するものとし、他の目的に利用してはなりません。

3. 利用企業は、候補者の同意なく、候補者の個人情報を第三者に提供してはなりません。

4. 利用企業は、次の各号に掲げる情報を候補者から収集してはなりません（職業安定法第5条の5および平成11年労働省告示第141号）。

   1. 人種、民族、社会的身分、門地、本籍、出生地その他社会的差別の原因となるおそれのある事項
   2. 思想および信条
   3. 労働組合への加入状況

5. 利用企業は、候補者の個人情報について、漏えい、滅失または毀損の防止その他の安全管理のために必要かつ適切な措置を講じるものとします。

6. 利用企業は、採用選考が終了した候補者の個人情報について、速やかに削除または返却するものとします。ただし、法令により保存が義務づけられている場合を除きます。

### 第10条（当社による個人情報の取扱い）

当社による個人情報の取扱いについては、別途定める[プライバシーポリシー](/privacy)によるものとします。

## 第4章 知的財産権

### 第11条（掲載コンテンツの権利）

1. 利用企業が本サービスに掲載した求人情報、企業ロゴ、写真、動画その他のコンテンツ（以下「掲載コンテンツ」といいます）の著作権その他の知的財産権は、利用企業または正当な権利者に帰属します。

2. **利用企業は、当社に対し、掲載コンテンツを本サービスの提供、宣伝、広告および広報の目的で、無償、非独占的に、複製、公衆送信、翻案および改変する権利を許諾するものとします。** 当該許諾は、本サービスの利用終了後も、当社が既に作成した広告物等について存続します。

3. 利用企業は、掲載コンテンツについて、第三者の知的財産権、肖像権その他の権利を侵害していないことを保証するものとします。

4. 掲載コンテンツに関し第三者との間で紛争が生じた場合、利用企業は自己の責任と費用においてこれを解決するものとし、当社に損害が生じた場合はこれを賠償するものとします。

### 第12条（本サービスの権利）

本サービスおよび本サービスに含まれる一切のコンテンツ（掲載コンテンツを除く）に関する知的財産権は、当社または正当な権利者に帰属します。

## 第5章 一般条項

### 第13条（免責）

1. 当社は、本サービスにおける候補者の登録情報の真実性、正確性および最新性について保証しません。利用企業は、自らの責任において採用選考を行うものとします。

2. **当社は、採用の成功、候補者の応募、スカウトへの返信、候補者の在籍継続その他の成果を保証しません。**

3. 当社は、利用企業と候補者との間に生じた紛争について、一切の責任を負いません。当該紛争は、利用企業と候補者との間で解決するものとします。

4. 当社が利用企業に対して負う損害賠償責任は、**当社の故意または重大な過失による場合を除き**、当該損害が発生した時点から遡って12ヶ月間に利用企業が当社に支払った金額（有料プランの料金の合計額）を上限とします。

5. 当社は、逸失利益、間接損害、特別損害および懲罰的損害について、責任を負いません。

### 第14条（本サービスの変更・中断・終了）

1. 当社は、利用企業への事前の通知なく、本サービスの内容を変更し、または提供を中断することができます。

2. 当社は、3ヶ月前までに利用企業に通知することにより、本サービスの提供を終了することができます。

### 第15条（反社会的勢力の排除）

1. 利用企業は、現在および将来にわたり、次の各号のいずれにも該当しないことを表明し、保証します。

   1. 暴力団、暴力団員、暴力団員でなくなった時から5年を経過しない者、暴力団準構成員、暴力団関係企業、総会屋等、社会運動等標榜ゴロ、特殊知能暴力集団等その他これらに準ずる者（以下「暴力団員等」といいます）
   2. 暴力団員等が経営を支配していると認められる関係を有すること
   3. 暴力団員等が経営に実質的に関与していると認められる関係を有すること
   4. 自己、自社もしくは第三者の不正の利益を図る目的または第三者に損害を加える目的をもってするなど、不当に暴力団員等を利用していると認められる関係を有すること
   5. 暴力団員等に対して資金等を提供し、または便宜を供与するなどの関与をしていると認められる関係を有すること
   6. その他暴力団員等と社会的に非難されるべき関係を有すること

2. 利用企業は、自らまたは第三者を利用して、次の各号に該当する行為を行わないことを保証します。

   1. 暴力的な要求行為
   2. 法的な責任を超えた不当な要求行為
   3. 取引に関して、脅迫的な言動をし、または暴力を用いる行為
   4. 風説を流布し、偽計または威力を用いて当社の信用を毀損し、または当社の業務を妨害する行為
   5. その他前各号に準ずる行為

3. 利用企業が前2項に違反した場合、当社は、何らの催告なく直ちに本サービスの利用を停止し、または本規約に基づく契約を解除することができます。この場合、当社は利用企業に生じた損害について一切の責任を負いません。

### 第16条（利用停止および解除）

1. 当社は、利用企業が次の各号のいずれかに該当する場合、事前の通知なく、本サービスの利用を停止し、または本規約に基づく契約を解除することができます。

   1. 本規約のいずれかの条項に違反した場合
   2. 有料プランの料金の支払を遅滞した場合
   3. 支払停止もしくは支払不能となり、または破産手続開始、民事再生手続開始、会社更生手続開始、特別清算開始の申立てがあった場合
   4. 手形または小切手が不渡りとなった場合
   5. 差押え、仮差押え、仮処分、強制執行または競売の申立てがあった場合
   6. 租税公課の滞納処分を受けた場合
   7. 6ヶ月以上本サービスを利用していない場合
   8. その他、当社との信頼関係が失われたと当社が判断した場合

### 第17条（利用終了）

利用企業は、当社所定の方法により、いつでも本サービスの利用を終了することができます。

### 第18条（秘密保持）

1. 利用企業および当社は、本サービスの利用に関連して知り得た相手方の秘密情報を、相手方の事前の書面による承諾なく第三者に開示または漏洩してはなりません。

2. 前項の義務は、本サービスの利用終了後も3年間存続します。

### 第19条（権利義務の譲渡禁止）

利用企業は、当社の事前の書面による承諾なく、本規約に基づく権利義務の全部または一部を第三者に譲渡し、または担保に供してはなりません。

### 第21条（規約の変更）

1. 当社は、次の各号のいずれかに該当する場合、民法第548条の4に基づき、本規約を変更することができます。

   1. 変更が利用企業の一般の利益に適合する場合
   2. 変更が契約の目的に反せず、変更の必要性、変更後の内容の相当性その他の事情に照らして合理的な場合

2. 当社は、本規約を変更する場合、変更後の規約の内容および効力発生時期を、本サービス上に掲示する方法により、効力発生日の**30日前まで**に周知するものとします。

3. **前項にかかわらず、次の各号に掲げる事項を変更する場合、当社は、当該各号に定める期間前までに利用企業に対し個別に通知するものとします。**

   | 変更事項 | 事前通知期間 |
   |---|---|
   | **掲載を有料化する場合**（第4条第1項の変更） | **90日前** |
   | **有料プランの内容または料金**（第5条） | **30日前** |

4. **前項に定める変更の効力発生日より前に開始した掲載および有料プランの利用については、変更前の条件が適用されます。**

5. **利用企業は、第3項に定める変更に同意しない場合、効力発生日までに第17条に定める方法により本サービスの利用を終了することができます。** この場合、変更後の条件は適用されません。

### 第22条（分離可能性）

本規約のいずれかの条項が無効または執行不能と判断された場合であっても、他の条項の有効性には影響しないものとします。

### 第23条（準拠法および管轄）

1. 本規約の準拠法は日本法とします。

2. 本規約に関する一切の紛争については、**東京地方裁判所**を第一審の専属的合意管轄裁判所とします。
