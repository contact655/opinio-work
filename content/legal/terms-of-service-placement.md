## 第1章 総則

### 第1条（目的および適用）

1. 本規約は、株式会社Opinio（以下「当社」といいます）が提供する採用支援プラットフォーム「OPINIO」（以下「本サービス」といいます）の利用に関し、当社と本サービスを利用する企業（以下「利用企業」といいます）との間の権利義務関係を定めることを目的とします。

2. 利用企業は、本サービスの利用を開始した時点で、本規約の全ての内容に同意したものとみなされます。

3. 当社は、有料職業紹介事業者（許可番号：13-ユ-316441）として本サービスを提供します。

### 第2条（定義）

本規約において使用する用語の定義は、次のとおりとします。

| 用語 | 定義 |
|---|---|
| **候補者** | 本サービスに登録している求職者 |
| **求人情報** | 利用企業が本サービス上に掲載する募集に関する情報 |
| **スカウト** | 利用企業が本サービス上の機能を用いて候補者に送信するメッセージ |
| **応募** | 候補者が本サービス上の機能を用いて求人情報に応募する行為 |
| **プラットフォーム接触** | 第10条第1項に定める、スカウトの送信または応募のいずれかが最初に発生した事実 |
| **採用決定** | 利用企業と候補者との間で雇用契約（正社員、契約社員その他雇用形態を問わない）が成立すること |
| **理論年収** | 第8条第2項に定める算定方法により算出される金額 |
| **エージェントサービス** | 当社が本サービスとは別に提供する人材紹介サービス |
| **有料プラン** | 第4条第3項に定める、当社が提供する有料の追加機能または役務 |
| **料金規約** | 有料プランの内容、料金および支払条件を定めるものとして当社が別途定める規約 |

### 第7条（成功報酬の免脱を目的とする行為の禁止）

1. 利用企業は、第8条に定める成功報酬の支払を免れることを目的として、次の各号に定める行為を行ってはなりません。

   1. 候補者に対し、本サービスを退会するよう求める行為
   2. 候補者に対し、本サービス外の連絡手段への切替えを求め、本サービス上の記録を残さないようにする行為

   4. 雇用契約を業務委託契約その他の形式に仮装する行為

## 第3章 成功報酬

### 第8条（成功報酬）

1. **利用企業は、プラットフォーム接触があった候補者を採用決定した場合、当社に対し、本条に定める成功報酬を支払うものとします。**

2. **成功報酬の額は、次の算式により算出される額とします。**

   > **成功報酬 ＝ 理論年収 × 15％**
   >
   > **ただし、上記により算出される額が500,000円（税別）を下回る場合、成功報酬は500,000円（税別）とします。**

3. **理論年収の算定方法**

   理論年収とは、利用企業が候補者に提示した年間の賃金総額であり、次の各号に掲げる金額の合計額とします。

   | 含むもの | 含まないもの |
   |---|---|
   | 基本給（月額×12ヶ月） | 実績に応じた変動賞与のうち、支給が確約されていない部分 |
   | 固定残業代（みなし残業代） | 実費弁償の性質を有する手当（通勤手当、出張手当等） |
   | 諸手当（役職手当、住宅手当、資格手当等） | 退職金 |
   | 賞与（支給が確約されている額） | 社会保険料の事業主負担分 |
   | 年俸制の場合は年俸額 | ストックオプション等の株式報酬 |

   ※ 賞与額に幅がある場合は、その最低保証額を用いるものとします。
   ※ 試用期間中の賃金が本採用後と異なる場合は、本採用後の賃金を基準とします。

4. 成功報酬には消費税が別途加算されます。

### 第9条（採用決定の報告および支払）

1. **利用企業は、候補者の採用を決定した場合、決定後速やかに（遅くとも5営業日以内に）、当社所定の方法により報告するものとします。**

2. 利用企業は、当該候補者の入社日および理論年収の内訳を当社に通知するものとします。

3. **当社は、候補者の入社月の末日を締日として請求書を発行し、利用企業は翌月末日までに当社指定の銀行口座に振り込む方法により支払うものとします。** 振込手数料は利用企業の負担とします。

4. 利用企業が支払を遅延した場合、支払期日の翌日から支払済みに至るまで、年**14.6％**の割合による遅延損害金を支払うものとします。

5. **候補者が入社日前に内定を辞退した場合、または入社しなかった場合、成功報酬は発生しません。**

### 第10条（プラットフォーム接触の定義および経路判定）

1. **「プラットフォーム接触」とは、利用企業と候補者との間で、次の各号のいずれかが最初に発生した事実をいいます。**

   1. **利用企業が、本サービス上の機能を用いて当該候補者にスカウトを送信したこと**
   2. **当該候補者が、本サービス上の機能を用いて利用企業の求人情報に応募したこと**

2. **利用企業が候補者のプロフィールを閲覧したにとどまる場合は、プラットフォーム接触には該当しません。**

3. **プラットフォーム接触が発生した日から12ヶ月以内に、利用企業が当該候補者を採用決定した場合、その採用経路のいかんを問わず、本条に定める成功報酬が発生します。** これには、次の場合を含みます。

   1. 利用企業が候補者と本サービス外で直接連絡を取り、採用した場合
   2. 候補者が利用企業の自社採用サイト等から改めて応募し、採用した場合
   3. 利用企業のグループ会社、子会社または関連会社が採用した場合

4. **エージェントサービスとの関係**

   当社がエージェントサービスにおいて利用企業に対し候補者を推薦した場合、当該推薦は本規約の適用対象外とし、エージェントサービスに関する個別契約に定める料率が適用されます。

5. **プラットフォーム接触とエージェントサービスによる推薦の双方が存在する場合、先に発生した方の経路を適用します。**

6. **前項において、先後関係が明確に判定できない場合は、本規約に定める成功報酬（理論年収の15％）を適用します。**

7. 当社は、プラットフォーム接触の事実およびその日時について、本サービスのシステムログをもって証明するものとします。

### 第10条の2（転職勧奨の禁止）

1. **当社は、当社の紹介により就職した求職者に対し、就職した日から2年間、転職の勧奨を行いません。** これは、職業紹介事業の許可条件（2025年1月1日施行）に基づく当社の義務です。

2. 前項には、本サービス上でのスカウトの送信を含みます。当社は、当該求職者が本サービス上で利用企業からスカウトを受信しないよう、必要な措置を講じます。

### 第10条の3（お祝い金等の禁止）

1. **当社は、求職者に対し、就職を勧奨する目的で、いわゆる「お祝い金」その他の金銭等を提供しません。**

2. **利用企業も、当社を通じて、または本サービスの利用に関連して、求職者に対し前項に定める金銭等を提供してはなりません。**

### 第11条（返戻金）

1. **利用企業が採用決定した候補者が、入社日から起算して30日以内に自己都合により退職した場合、当社は、利用企業が支払済みの成功報酬の全額（100％）を返還します。**

2. **前項の規定は、次の各号のいずれかに該当する場合には適用しません。**

   1. **退職が利用企業の都合による場合**（解雇、退職勧奨、事業所の閉鎖、経営上の理由による人員削減等）
   2. **利用企業が候補者に提示した労働条件が、求人情報の内容と異なっていた場合**
   3. **利用企業におけるハラスメント、違法行為または労働関係法令違反が退職の原因となった場合**
   4. **候補者の退職後1年以内に、利用企業（グループ会社、子会社および関連会社を含む）が当該候補者を再び雇用し、または業務委託その他の契約により役務の提供を受けた場合**
   5. **利用企業が第9条第3項に定める支払期日までに成功報酬を支払わなかった場合**
   6. 利用企業が本規約に違反した場合
   7. 候補者の退職について、利用企業が当社に対し虚偽の報告を行った場合

3. 前項第4号に該当する場合、利用企業は、既に返還を受けた返戻金の全額を当社に返還するものとします。

4. **利用企業は、候補者が退職した場合、退職日から14日以内に当社に対し、退職の事実、退職日および退職事由を報告するものとします。** 当該報告がない場合、当社は返戻金の返還義務を負いません。

5. 当社は、退職事由の確認のため、利用企業および候補者に対し、必要な情報の提供を求めることができます。

6. 返戻金の返還は、当社が退職事由を確認した後、利用企業の指定する銀行口座への振込により行います。

### 第12条（候補者の個人情報の取扱い）

1. 利用企業は、本サービスを通じて取得した候補者の個人情報について、個人情報の保護に関する法律、職業安定法およびこれらに基づく指針を遵守し、適正に取り扱うものとします。

2. 利用企業は、候補者の個人情報を、**採用選考の目的のみに利用**するものとし、他の目的に利用してはなりません。

3. 利用企業は、候補者の同意なく、候補者の個人情報を第三者に提供してはなりません。

4. 利用企業は、次の各号に掲げる情報を候補者から収集してはなりません（職業安定法第5条の5および平成11年労働省告示第141号）。

   1. 人種、民族、社会的身分、門地、本籍、出生地その他社会的差別の原因となるおそれのある事項
   2. 思想および信条
   3. 労働組合への加入状況

5. 利用企業は、候補者の個人情報について、漏えい、滅失または毀損の防止その他の安全管理のために必要かつ適切な措置を講じるものとします。

6. 利用企業は、採用選考が終了した候補者の個人情報について、速やかに削除または返却するものとします。ただし、法令により保存が義務づけられている場合を除きます。

   4. 風説を流布し、偽計または威力を用いて当社の信用を毀損し、または当社の業務を妨害する行為
